📌 ポイント

1. 「やってくれるAI」と「聞けるAI」の違い

ChatGPTは答えを教えてくれる「聞けるAI」。Claude Code・Cursorは実際にコードを書いて実行まで完結させる「やってくれるAI」。業務自動化はこの「やってくれるAI」に任せることで初めて成立する。自分がプログラムを書けなくても、「こういうワークフローを作りたい」と伝えるだけで設計から実装まで進められる。

2. 営業リード自動獲得システムの構造

PRタイムズの新着プレスリリースを収集→スコアリング（儲かってそうな企業・従業員数基準）→企業ページから問い合わせフォームURLを抽出→Playwrightでフォームを自動入力・送信という流れをゼロから約30分で構築。企業別にプレスリリース内容を読んだ上でカスタム営業文を生成するため、精度の高い営業が可能。毎朝9時スケジュール実行に設定し、以後は無人で動き続ける。

3. X（Twitter）記事自動生成の構造

「週2〜3本、5000〜8000字の記事下書きを自動生成したい」と伝えるだけでワークフローが自動設計される。AIトレンドニュースを収集→要点抽出→記事化→レビュー&下書き保存というパイプラインが出来上がる。Xのデータ取得はブロック対策として自前のAPIキーやbot認証が必要になる場合があるが、対処法もClaude Codeが提示してくれる。記事はノートで有料サブスク展開との組み合わせで月数十万規模の収益化も可能。

4. スライド自動作成の2パターン

PowerPointはビジネスライクで編集可能・画像生成は派手だが編集不可という使い分けがある。画像生成パターンではOpenAI APIキーを取得してClaude Codeに渡すだけで、構成案を伝えるだけで視覚的なスライドが自動生成される。APIキー取得（OpenAI Platform → Create API Key）が唯一の難関で、それ以外は質問に答えるだけで完結する。

5. AI導入支援ビジネスとしての展開

法人向けにAI業務自動化を週1回導入支援するだけで月50〜100万の契約が取れる時代が到来している。この動画で実演した営業自動化システムは受託すれば100万の案件相当。今回作った仕組みはそのまま売却・譲渡も可能で、俗人性がないため事業売却（M&A）にも向く。競合優位はスピードと「やりきる」こと。同じ動画を見ても行動する人は少数派。

💡 ゆりこの活用メモ

① 明日の朝、Claude Codeで「AI導入支援の営業リスト自動化」を試してみる PRタイムズは公開情報なのでスクレイピング可能。「クライアント候補を自動で毎日10社リストアップしたい」とClaude Codeに伝えるだけで設計が始まる。コード知識ゼロでOK。

② 社内AI推進の提案資料をスライド自動生成で作ってみる OpenAI APIキー（無料枠あり）を取得してClaude Codeに渡す。「AI導入ロードマップのスライドを作って」と言えば視覚的なスライドが生成される。PPTX形式で出力すれば編集も可能。
