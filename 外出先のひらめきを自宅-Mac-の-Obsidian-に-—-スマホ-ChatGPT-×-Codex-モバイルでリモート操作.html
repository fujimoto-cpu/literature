📌 ポイント

1. Codex Mobile とは — ChatGPT からリモートで Mac を操作する仕組み

ChatGPT の新機能「Codex Mobile」を使うと、スマホアプリから自宅 Mac の Codex Desktop に接続し、Obsidian の Vault をそのまま操作できる。QR コードを読み取るだけでセットアップ完了（約 30 秒〜1 分）。現在プレビュー期間中のため、無料プラン・Go プランでも利用可能。

2. セットアップ手順 — QR コード読み取りのみ

① Mac に Codex Desktop をインストール・ChatGPT アカウントでログイン → ② アプリ左下のスマホアイコンをクリック → ③ QR コードをスマホで読み取り → ④ スマホの ChatGPT アプリに「Codex」ボタンが表示されれば接続完了。モバイル側でスキルを使いたい場合は「$スキル名」ではなく「このスキルを使って〜」と明示的に指示する必要がある。

3. スリープ対策 — 外から繋ぐには Mac を起こしておく

Mac 側の「電源アダプター使用時はディスプレイオフでスリープしない」をオン、さらに Codex アプリ設定 > 接続 > 「電源接続中はスリープしない」もオンにする。ノート PC ユーザーは必須設定。デスクトップ Mac なら不要なケースが多い。

4. Claude のリモートコントロールとの違い

Claude リモートコントロールはブラウザ URL 経由で会話の疎後がなく、CLI との双方向同期も取れる。一方 Codex Mobile はアプリ間通信のみで、スマホ側の会話が CLI 側に反映されない制約がある。Claude はプロ以上が必要、Codex Mobile は現在無料でも試せる点が大きな差。

💡 ゆりこの活用メモ

① 散歩・通勤中の音声入力でアイデアを Obsidian Inbox に直送 スマホに語りかけてアイデアを Codex と会話 → 「Inbox フォルダに要点まとめたメモを保存して」と指示。帰宅後すぐ続きに着手できる状態を作れる。AI 導入推進のアイデア出しにも使える。

② Claude 契約なしでも今すぐ試せる ChatGPT 無料プランで試して、安定して使いたくなったら Plus へ。明日の朝、Codex Desktop をインストールしてQRコード接続まで試してみる。
