📝 要約

🎯 Claude Code/Codexを使いこなす鍵は「フォルダ階層を整えて、各階層にエージェントMDを置く」こと。7つの道具（エージェントMD・フォルダ・スキル・MCP・権限・モード・フック）の役割を整理した社内講座。

🗺️ 全体像

flowchart TD
    A[フォルダ階層を整える] --> B[各階層にエージェントMDを置く]
    B --> C[開いた場所から上のMDが全部読まれる]
    C --> D[スキル：必要な時だけ呼ぶ]
    C --> E[MCP：Gmail・Drive等とつなぐ]
    E --> F[権限JSON：絶対守る禁止事項]
    F --> G[モード・フック：承認と自動実行]

📌 ポイント

1. エージェントMD — 必ず最初に読まれる指示

名前を「エージェントMD」にすると、そのフォルダで作業を始めた瞬間に必ず読み込まれる。Webのカスタム指示が1つなのに対し、フォルダごとに置ける。名前を変えると読まれない。

2. フォルダ階層 — 命と言い切る

AIはまずファイル名・フォルダ名で検索する（AI的な意味検索ではなく完全一致寄り）。クライアント別・受注済み別などで整理し、名前を整えると検索しやすくなる。開いた場所から上位のMDが全部読まれるため、階層ごとに会社情報→契約→サービス内容と段階的に書いておけば、事前入力ゼロで始められる。PowerPointや画像はAIが読みにくいので、MDやテキストで残す。

3. スキル — 控えのメンバー

エージェントMDが常にスタメンなら、スキルは必要な時だけ呼ぶ控え。コンテキストを圧縮するための仕組み。講師は100個ほど所持。

4. MCP — 外部ツール接続

Gmail・ドライブ・カレンダー・Slack・Salesforceなどにつなぐ。講師は24個接続。つながないと意味が薄いという立場。

5. 権限JSON・モード・フック — セキュリティ

「メールは送らない」などはエージェントMDに書くより、JSONの権限設定に書けばシステム的に絶対守られる。フックは「終わったら通知音を鳴らす」のように、決まったタイミングでプログラムを動かす。

💡 ゆりこの活用メモ

① 自分のvaultの階層確認：CLAUDE.mdが階層ごとにあるかを見直す。今の構成はこの方針とほぼ同じ。 ② 守らせたいルールは権限設定に：「即興コマンド禁止」のような禁止事項は、文章だけでなく設定側で止める方が確実という裏付け。
