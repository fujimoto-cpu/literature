📝 要約

🎯 Obsidianをカスタマイズするコアプラグイン3つ（デイリーノート・キャンバス・WebViewer）とコミュニティプラグイン5つ（Typing Assistant・Reveal Active File Button・Recent Files・2Hop Links Plus・Omnisearch）を厳選紹介する動画。プラグイン探しに時間を溶かすのではなく、まず最小限の8つを入れてメモを書く時間を確保するのが本質。

🗺️ 全体像

flowchart TD
    A[コアプラグイン3つ] -->|デイリーノート/キャンバス/WebViewer| B[最初にこれだけ入れる]
    B --> C[コミュニティプラグイン5つ]
    C -->|Typing Assistant/Reveal Active File/Recent Files/2Hop Links Plus/Omnisearch| D[検索・リンク・入力を高速化]

📌 ポイント

1. コアプラグイン3つ — Appleが作る標準機能

Obsidian左下の歯車→コアプラグインで確認できる。①デイリーノート：日付ごとに自動でメモが作られ、日付入力の手間がゼロになる。②キャンバス：テキストボックス・既存ノート・画像を空間に自由配置し、矢印でつないでマインドマップ化できる。読書・講義メモに向く。③WebViewer：外部リンクをObsidian内で直接開ける機能。タブを右分割すれば左でメモを書きながら右でWeb記事やYouTubeを見られる2画面運用ができる。

2. Typing Assistant — マークダウンを覚えなくていい

コミュニティプラグイン。インストール→有効化の2ステップで使える。本文中で「/」を打つとTo-Doリスト・コールアウト・引用・テーブルなどのメニューが出て、記法を覚えなくてもワンクリックで挿入できる。

3. Reveal Active File Button / Recent Files — 迷子防止

Reveal Active File Buttonは今開いているノートがフォルダ内のどこにあるかを一発で表示する（5000ファイル規模でも一瞬）。Recent Filesは直近に開いたファイル一覧を表示し、そこからキャンバスへドラッグ&ドロップで貼り付けることもできる。

4. 2Hop Links Plus / Omnisearch — リンクと検索の要

2Hop Links Plusはリンク先ノートの中身をボックス表示してくれる（Scrapbox由来の発想）。リンク先がまだ存在しない場合は赤色で表示され、クリックすると新規ファイルを即作成できる。Omnisearchはタイトルだけでなく本文中身までヒットする全文検索プラグインで、動画内では「一番愛用している」と紹介されている。

💡 ゆりこの活用メモ

① まず8つだけ入れる プラグイン探しで時間を溶かさないよう、動画で紹介された8つ（コア3+コミュニティ5）だけを今の状態からインストールし、それ以上は探さない。

② Omnisearchを検索の第一選択にする 「あのメモどこだっけ」となったらタイトル検索ではなくOmnisearchを使う癖をつける。Vaultが数千件規模なので効果が大きい。
