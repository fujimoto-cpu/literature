📝 記事内容

2026年6月1日の AI 11大ニュース。インフラ・資金・リスクが同時進行する転換点。

1. Anthropic 史上最大資金調達

  • 評価額 9,650億ドル（965B）で65億調達
  • OpenAI（$852B）を超え、プライベートAI企業として世界最高評価額
  • Q2 2026 収益予測：109億・営業利益5億5,900万
  • CEO Dario Amodei：「コンピュートインフラ・モデル開発・安全研究に充当」

2. $360億チップ融資（史上最大）

  • Apollo Global Management + Blackstone が $360億のプライベートクレジット枠を組成
  • Google TPU チップを Anthropic 向けに購入する史上最大のチップ融資案件
  • Broadcom が最大トランシェを保証。NY・TX・LA・IN 4州のデータセンター向け

3. SoftBank フランス投資

  • €750億（$875億）をフランスのAIデータセンター 5GW キャパシティに投資（2031年まで）
  • 「電力の70%が原子力の低炭素電力グリッド」をフランスの強みとして言及

4. Cognition（Devin）$10億調達

  • 評価額 260億で10億調達
  • Devin の ARR：12ヶ月で +1,230%（3,700万→4億9,200万）
  • 主要顧客：Goldman Sachs・NASA・Mercedes-Benz

5. GitHub Copilot トークン課金で炎上

  • 6月1日よりフラット料金→トークン課金に移行
  • 29/月→最大∗∗750/月** になる可能性との試算でSNS炎上
  • 「冗談だろ」という声多数

6. Wikipedia 編集者スト

  • AI によるコスト削減で Wikimedia Foundation がレイオフ → 編集者がスト
  • 「人間のファクトチェッカー・コミュニティリエゾンは不可欠」と主張

7. LLM によるサイバー攻撃（初確認事例）

  • Sysdig が CVE-2026-48710（BadHost）を悪用した自律型 LLM エージェントによるサイバー攻撃を記録
  • 1時間未満で AWS データベースを侵害した史上初確認事例

8. ヒューマノイドロボットをウクライナに派遣

  • Foundation Industries の Phantom MK-1 を戦場後方物流テストに投入
  • 戦闘区域への人型ロボット展開は軍事史上初

9. AGI は 2029年（Hassabis 見通し）

  • Google DeepMind CEO が AGI 予測を 2029年に更新
  • 定義：「幅広い認知タスクで概ね人間レベル」

10. OpenAI バイオ防衛イニシアチブ

  • Rosalind Biodefense Program を米政府向けにローンチ
  • Five Eyes パートナーにもアクセス提供（感染症モデリング・病原体監視）

11. Microsoft Build 2026 プレビュー

  • 6月2日開幕。自社製 MAI コーディングモデル・Azure AI Foundry・Agent 365 を発表予定
