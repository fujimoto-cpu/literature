📸 スライド内容

スライド 1

（画面上部に透かしロゴ「YEROJECT」）

① 단색 배경 만들기 (CTRL+Y) → 単色背景を作る（CTRL+Y） タイムラインパネル：レイヤー「[진한 회색 단색 1]」（濃いグレーの単色レイヤー）、モード：표준（標準）、トラックマット設定あり。

② 별 모양 생성 → 점 / 내부 반경 조절 → 星型シェイプを作成 → 点（頂点数）／内部半径を調整 「모양 속성」（シェイプ属性）パネル：

  • 유형（種類）: 별（星）
  • 점（頂点数）: 8
  • 회전（回転）: 0x+143.4°
  • 내부 반경（内部半径）: 57.6
  • 외부 반경（外部半径）: 165.2
  • 선 색상（線色）: 없음（なし）

スライド 2

③ 단어 단위로 텍스트 작성 (글자 수가 비슷할수록 GOOD) → 単語単位でテキストを作成する（単語ごとの文字数が近いほどGOOD） プレビュー：ダーク背景に濃いピンクの太字で「HOW / TO / MAKE / THIS / TEXT」を縦に配置、白い星型の装飾あり。 タイムラインパネル：テキストレイヤー「HOW」「TO」「MAKE」「THIS」「TEXT」の5レイヤー、モード：표준（標準）。

④ 각각 사전구성 만들기 (CTRL+SHIFT+C) → それぞれをプリコンポーズする（CTRL+SHIFT+C） タイムラインパネル：「[HOW 컴포지션 1]」「[TO 컴포지션 1]」「[MAKE 컴포지션 1]」「[THIS 컴포지션 1]」「[TEXT 컴포지션 1]」の5つのコンポジションレイヤー。

スライド 3

左上：After Effectsの「컴포지션(C)」（コンポジション）メニューを開いた状態。メニュー項目： 새 컴포지션(C)… Ctrl+N／컴포지션 설정(T)… Ctrl+K／포스터 시간 설정(E)／컴포지션을 작업 영역으로 다듬어 자르기(X) Ctrl+Shift+X／컴포지션을 관심 영역으로 자르기(I)（グレーアウト）／선택한 레이어 경계에 맞게 컴포지션 잘라내기（選択レイヤーの境界に合わせてコンポジションを切り取る＝赤枠で強調）／Adobe Media Encoder 대기열에 추가… Ctrl+Alt+M／렌더링 대기열에 추가(A) Ctrl+M／출력 모듈 추가(D)／미리 보기(P)／다른 이름으로 프레임 저장／미리 렌더링…

⑤ 텍스트 컴포지션 더블클릭 순서대로 클릭 (텍스트 크기에 맞게 컴포지션 크기가 맞춰짐) → テキストコンポジションをダブルクリックし、順番にクリックする（テキストサイズに合わせてコンポジションサイズが自動調整される） 右画像：「HOW TO MAKE THIS TEXT」の「HOW」レイヤーが選択され、変形ハンドルが表示された状態。

⑥ 각 텍스트 레이어에 모퉁이 고정 효과 적용 → 各テキストレイヤーに「모퉁이 고정（Corner Pin／コーナーピン）」エフェクトを適用する 「효과 및 사전 설정」（エフェクト＆プリセット）パネルで「모퉁이 고정」を検索 →「왜곡」（ディストート）カテゴリ内の「모퉁이 고정」（Corner Pin）。

スライド 4

⑦ 키프레임 활성화 후 위와 같은 모양으로 변경 → キーフレームを有効化した後、上図のような形に変更する 左画像：「HOW TO MAKE THIS」の文字が斜めのライン（赤線）に沿って歪んで配置されている図。 右画像の注記：「모퉁이 쪽 동그라미를 움직여 조절하면 됨!」→「コーナー側の丸（ハンドル）を動かして調整すればOK！」（「HOW TO MAKE」にコーナーピンのハンドル（小さい四角）が表示された状態） エフェクトコントロール「모퉁이 고정」（Corner Pin）の座標（다시 설정＝リセット）：

  • 왼쪽 위（左上）: -108.9, -0.0
  • 오른쪽 위（右上）: 928.3, 8.9
  • 왼쪽 아래（左下）: -106.6, 315.8
  • 오른쪽 아래（右下）: 930.5, 135.8

⑧ 모든 레이어에 적용 → すべてのレイヤーに適用する タイムラインのキーフレームパネル：「모퉁이 고정」の4点（왼쪽 위／오른쪽 위／왼쪽 아래／오른쪽 아래）にそれぞれキーフレームが打たれている（00:15f・01:00f・01:15f・02:00f付近）。 注記画像2枚：「HOW 왼쪽으로 늘어나는 모양」→「HOWが左に伸びる形」／「HOW 오른쪽으로 늘어나는 모양」→「HOWが右に伸びる形」（キーフレームごとに左右へ伸び縮みする「HOW」のスクリーンショット）。

スライド 5

プレビュー：「HOW TO MAKE THIS TEXT」の輪郭がザラついた（グランジ・かすれた）質感になった最終仕上がり。丸で囲った拡大図で「TO MAKE」部分の輪郭のザラつきを拡大表示。

エフェクトコントロールパネル（エフェクトスタック）：

  • CC Scatterize（散乱）: Scatter 3.0／Right Twist 0x+0.0°／Left Twist 0x+0.0°／Transfer Mode: Composite
  • 패스트 박스 블러（Fast Box Blur）: 흐림 반경（ぼかし半径）1.0／반복（繰り返し）3／흐림 차원（ぼかし方向）가로 및 세로（横＆縦）／가장자리 픽셀 반복（エッジピクセル繰り返し）チェック済み
  • 레벨（レベル補正）: 채널（チャンネル）알파（アルファ）／ヒストグラム表示／알파 입력 검정（アルファ入力・黒点）9.0／알파 입력 흰색（アルファ入力・白点）67.0／알파 감마（アルファガンマ）1.00／알파 출력 검정（アルファ出力・黒）0.0／（출력 흰색＝出力白）255.0／32bpc 색상에 대해 해제（32bpcカラーに対して解除）×2箇所

注記：「그런지 효과 주는 법! (위 효과 수치 참고)」→「グランジ効果の付け方！（上記のエフェクト数値を参照）」

💡 Creative Direction Note

🎯 単語ごとに分けたテキストレイヤーをCorner Pin（コーナーピン）で個別に歪ませて“伸び縮みする”モーションを作り、CC Scatterize＋レベル補正でグランジ質感を重ねるAfter Effectsのテキストモーション・チュートリアル。

1. 単語単位のレイヤー分割 → 個別プリコンポーズ＋Corner Pin

単色背景＋星型シェイプで装飾を作った後、テキストを単語ごとに別レイヤーに分ける（文字数を揃えると仕上がりが綺麗になる、とキャプションにも明記）。各テキストをCtrl+Shift+Cでプリコンポーズし、コンポジションをテキストサイズにフィットさせてからCorner Pin（モーション歪み効果）を全レイヤーへ適用する、という「量産できる」下ごしらえの型。

2. Corner Pinのキーフレームで「伸びる」「歪む」を作る

左上・右上・左下・右下の4点座標をキーフレーム化し、外側のコーナーだけを左右非対称に動かすことで「左に伸びる」「右に伸びる」という一瞬歪むアニメーションを作る。中心を固定して外側だけ振るのがポイント。

3. CC Scatterize＋ボックスブラー＋レベル（アルファ）でグランジ質感

最後にCC Scatterize（散乱）・Fast Box Blur・Levels（アルファチャンネル）を重ねて輪郭をザラつかせ、手描き風グランジのテクスチャに仕上げる。数値例：Scatter 3.0、ブラー半径1.0×3回、アルファ入力黒9.0／白67.0。

💡 ゆりこの活用メモ

① SNS告知バナーの見出しに転用 BIGBANGやLAVANDAなどの告知ビジュアルで「タイトルが一瞬伸び縮みする」演出は、この単語分割＋Corner Pinの型をそのまま真似できそう。まず単色背景＋文字を単語で割るところから試してみる。

② ロゴのグニャッと歪む演出にも応用 Corner Pinの4点キーフレームは、KONNEKTロゴや案件ロゴをオープニングで歪ませる演出にも転用できる。数値の振り方（外側だけ動かす）をそのまま参考にする。

③ グランジ加工の引き出しとして保存 CC Scatterize＋レベル（アルファ）の組み合わせは、装飾少なめの案件で「手作り感」「ラフさ」を足したいときの手数として使える。
