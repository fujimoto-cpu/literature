📌 ポイント

1. AIスペシャリストとは何か — エンジニアとビジネスの「間」の存在

従来AIに強かった人は「エンジニア（コード寄り）」か「驚き屋（発信・マーケ寄り）」の二極だった。しかし claude-code / Cursor / バイブコーディングの台頭で境界線が消え、両方を兼ね備えた「AIスペシャリスト（GTMエンジニア的存在）」が生まれた。ビジネス課題を理解してAIで高速解決し、社内に展開できる人材のこと。日本ではまだ職種名すら定着していないが、年収3000万クラスも出始めている。

2. スキルセット① AIエージェントを実際に使いこなす

Claude Code / Codex / Cursor などのコーディングエージェントを「ツールとして覚える」レベルではなく、社内の実業務を1件でも速度重視で自動化した経験が必須。バグっていてもOK・バイブコーディングで直せばいい、という感覚を身につけることが大切。ai-agent（スキルズ・エージェントチーム・コンテキスト管理など）AI独特の概念も習得する必要がある。

3. スキルセット② 自社・クライアントのビジネスを深く分かっている

外部エンジニアより、社内事情を熟知した人間がAIでツールを作る方が圧倒的に速い。要件定義ヒアリングに1〜2時間かけるより、分かっている人が1日でバイブコーディングして納品する方が価値が高い。自分のドメイン知識（YouTube運用・広告・ECなど）と組み合わせることで差別化できる。

4. スキルセット③ 組織全体にAIを展開・浸透させられる

自分が使えるだけでは不十分。ツールを作り→手順書化し→社員に教え→フィードバックを受けて改善するサイクルを回せる人が最も価値が高い。AIトランスフォーメーションを一人で牽引できる人材はCAIO的な立ち位置で、月収200万での採用事例もある。コンサルタントとの違いは「資料を出して帰る」ではなく「チームビルディングまで一緒にやる」点。
