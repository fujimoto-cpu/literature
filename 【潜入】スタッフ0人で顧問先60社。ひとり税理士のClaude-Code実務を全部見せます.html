要約（2026-06-29 wiki-ingest）

京都在住の税理士・畠山健人氏（キャリア16年・独立2年目）が、スタッフゼロで顧問先60社を一人で回す仕組みを公開したYouTube動画。2026年2〜3月から claude-code を使い始め、わずか2ヶ月で業務の大部分をAIに委任できるようになったと語る。

非エンジニアでも実現できた理由として「業務設計能力（上場企業監査・事業会社経験で培ったフロー設計力）+ AIによるコーディング代替」の掛け合わせを挙げる。プログラミングは claude-code が書いてくれるため、自分はプロンプトで指示するだけでよい。

実務での活用フローは主に3段階。①問い合わせがあったらリードフォルダを自動生成→相手のWebサイトをスクレイピングして人物・サービス情報を自動調査・整理 ②Notion AIで文字起こしした議事録を自動要約→提案書（Word）まで自動生成 ③クラウド会計ソフト（freee）の登録タスクをPythonスクリプトで夜間バッチ処理。PCはGoogleリモートデスクトップで付けっぱなしにして、外出中でもスマホから指示を出せる体制。

ai-workflow の観点では「スキル化」が重要なキーワードとして登場する。繰り返し使う業務フローは claude-code にスキルとして記憶させ、「次はこれやって」の一言で実行できる状態を目指している。会計ソフトはfreeeかマネーフォワードのクラウド系のみ対応可能で、TKC・JDLなどはAI連携不可という制約も明言。

「Windowsが初めて出てきたときのインパクト」「紙のままやり続けた組織との差はそれと同じレベルになる」という強い危機感と共に、一人事務所モデルの利益率の高さ・採用問題からの解放をメリットとして訴える。税理士業界以外でも応用できる営業効率化（リサーチ→議事録→提案書の自動化）が核心。
