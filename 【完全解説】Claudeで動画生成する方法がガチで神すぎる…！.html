📝 要約

🎯 Claude Code × HixField MCP を連携させることで、プログラミング不要で画像・動画・音声生成AIを自分のPCから統合操作できる。API高額問題を統合プラットフォームのサブスクで解決する実践解説。

📌 ポイント

1. HixField MCP でできること

Claude（デスクトップアプリ）の設定から MCP コネクタを追加するだけで、HixField が提供する50種類以上の生成AIモデル（画像・動画・音声・3D）をチャット上から直接動かせる。コピペ不要・ファイルのアップロード不要。Claude がフォルダを直接参照して生成・保存・整理まで行う。

2. API高額問題を統合プラットフォームで回避

各社の生成AI（KlingAI等）を直接 API 経由で使うと企業向け高額料金がかかるが、HixField のサブスク（Ultraプラン月99ドル）を MCP 経由で使えば、月3000クレジットの範囲で Seedance2.0の動画40本・GPT Image2の画像750枚相当が使える。

3. Claude Code × オープンソースツールで能力無限拡張

Claude Code はコマンドでオープンソースツールを自動インストールして活用できる。例として DEMUCS（無料・商用OK）で音楽のボーカルと伴奏を分離し、リップシンク精度を向上させる作業を「音源パスを貼り付けて分離して」の一言で完結させた。

4. MV制作ワークフローの全体像

①Claude でフォルダ整理 → ②GPT Image2 で素材画像生成（ロゴ入りヘッドホン等） → ③Seedance2.0 で動画生成 → ④Klingアバターでリップシンク（手動UI）→ ⑤動画編集ソフトで組み合わせ。用途ごとに最適モデルを使い分けられるのが統合プラットフォームの最大の強み。

💡 ゆりこの活用メモ

① HixField MCP を Claude Code に接続してみる 設定→コネクタ→カスタムコネクタ追加の3ステップだけ。試しにアパレル案件のイメージボード用の素材を複数バリエーションで一気に生成できるか検証してみる価値あり。

② 案件の素材整理を Claude に任せる ファイル名がバラバラでも画像の中身を認識してフォルダ分けしてくれる機能は、撮影素材の整理や参考画像の振り分けにそのまま使える。

③ ボーカル分離は動画・音声案件（柳田家MV等）でも使える DEMUCS でボーカル抽出→リップシンクの流れは、MVやプロモ動画制作に応用可能。Claude Code に「分離して」と言うだけで環境構築から実行まで完結する点が大きい。
