📝 要約

🎯 「AIっぽさ」の差はプロンプトの上手さでなくデザインの進め方。Claude Designで①プロンプトをAIに作らせる→②参考画像でデザインシステムを作る→③システムを使って各セクションを作る→④Claude Codeで完成、という全工程の実演。

📌 ポイント

1. プロンプトはAIに作らせる

Claudeの通常チャットで、やりたいことを数行伝えて「詳細なプロンプトをマークダウン形式で」と依頼し、mdをダウンロードしてClaude Designに添付する。初版（アイスクリーム注文サイト）は誰でもできるレベルで、プロのデザイナーが見れば一目でAI製と分かる出来。

2. デザインシステムが一番強力な機能

余白・背景・角丸・色・ボタン・フォーム欄まで決めた設計書が、参考画像を入れるだけで約5分で出る。Figmaデータ、GitHub、ロゴ・フォント・素材からも作れる。システムは英語が中心。以前は何時間〜何か月かけて手で作っていたもの。

3. 参考はPinterestで「真似でなくインスピレーション」

英語で検索し、柔らかく可愛い雰囲気の画像を集めて素材にする。システム適用後は、スクロール連動のパララックスを足す、アクセントカラーやスクープ数・価格表示を設定で切り替える、といった調整が可能。

4. 画像はChatGPT、公開はClaude Code

Claudeは画像生成ができないため、ChatGPTで背景透過しやすい単体画像を作って差し替える。仕上げは共有メニューからClaude Codeに送る（コピープロンプト／ローカル保存）。同じデザインシステムで店内メニュー（A4）やInstagramの4枚カルーセルも数分で作れ、スタイルが統一される。

💡 ゆりこの活用メモ

① ブランドごとにデザインシステムを1つ作る LAVANDAなど継続案件のロゴ・色・フォントを素材に、システムを1つ作って提案資料やSNS画像に使い回す。

② 参考画像はコピーでなく解釈の材料にする 手元の参考画像（ref-collector）をそのままシステム作成に入れて、初版との差を見る。
