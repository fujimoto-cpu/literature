🎯 Obsidianに「claudian」プラグインを入れることで、クロードコードとのチャットパネルをサイドバーに常駐させ、ノートを見ながらAIに編集・生成を依頼できる環境を構築できる。Google Driveによる複数端末同期と組み合わせることで、どのPCからでも同じノートをAIと編集できる「AIメモ環境」が完成する。

📌 ポイント

1. claudian — ObsidianとClaude Codeをつなぐプラグイン

Obsidianのサイドバーにクロードコードのチャットパネルを表示するプラグイン。ノートを書きながら右側のパネルでAIに「このメモを整理して」「文章を生成して」と直接指示できる。VS Codeやanticgravity（アンチグラビティ）でも同様のことはできるが、Obsidianはマークダウンの表示が見やすく、文章作業に特化した環境として優れている。

2. BRATプラグイン経由でのインストール方法

claudianは現在Obsidianの公式コミュニティプラグインに未掲載のため、BRAT（Beta Reviewers Auto-Update Tester）を経由してインストールする。手順は「コミュニティプラグイン → BRATを検索・インストール → Add Beta Plugin → claudianのGitHub URLを入力 → Add Plugin」の5ステップ。インストール後、ターミナルで claude コマンドを実行してログインすれば、サイドバーにチャットパネルが出現する。

3. Google Driveによる複数端末同期

Obsidianには自動同期機能がないため、パソコン版Google Driveをインストールし、Obsidianの保管庫フォルダを同期対象に追加する。別の端末ではGoogle Driveからフォルダをオフライン化し、Obsidianの「保管庫としてフォルダを開く」で読み込めばOK。Mac・Windowsどちらでも同じノートをclaudianで編集できる。注意点として .obsidian フォルダ（設定ファイル）も丸ごと同期されるため、別端末で設定がバグる可能性がある（柔軟な制御が必要ならGitHubによる同期が推奨）。

4. Obsidianの基本機能と設定ポイント

マークダウン記法（# で見出し、- で箇条書き）で文章を書け、グラフビューでノート間のリンクを視覚化できる。Canvasではボード上にノートを配置して思考を整理可能。保管庫は複数作成でき、プロジェクトごとに分けられるが、プラグイン設定は保管庫ごとに独立している。エディタ設定（行の長さ・改行）、新規ノートの作成場所、添付ファイルの保存先、テーマ（外観）は最初に確認しておくと快適。
