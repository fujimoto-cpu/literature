📝 要約

🎯 Claude Codeのサブエージェント機能で「ホームページ制作会社」を丸ごとバーチャル化し、PMのAIがスタッフAI社員（ディレクター・コピーライター・デザイナー・コーダー・品質管理・インフラ・経理）を自動で雇用・指揮してLP制作からVercel公開までを完全自律でやり切らせた事例。社長（人間）の仕事は指示・承認の4回だけ。

    B -->|承認| C[👥 スタッフAI社員を雇用]

    G --> H[💰 経理AI: トークン費用集計]

📌 ポイント

1. PM主導のサブエージェント編成 — 「雇用」という比喩でタスク分配

クロードコードのサブエージェント機能を使い、PM役のAI「締め切り守るくん」があらかじめ用意された役割別のサブエージェント（ディレクター・コピーライター・デザイナー・コーダー・品質管理・インフラ担当・経理）を必要なタイミングで「雇用」し作業を割り振る。人間が個別に指示を出す必要がなく、PMが責任を持って段取り・進行管理・報告まで担う設計。

2. 社長（人間）の関与は4回だけ — 受注→承認→承認→公開判断

実際の制作会社と同じ流れで、①最初にLP制作の要件を1回伝える ②PMが作った構成案を承認する（自動承認モードなら不要）③納品物を確認して承認する ④公開するかどうかを最終判断する、の4ステップのみ。それ以外は全部バックグラウンドでAIエージェントたちが自律的に進める。

3. デプロイまで一気通貫 — MCPでVercel接続

インフラ担当のAI社員がクロードコードとMCP（Model Context Protocol）でVercelを接続しており、承認が出れば公開作業まで自動でやってくれる。独自ドメインを与えればそこへの公開も可能。人間のエンジニアが介在せず、生成→検品→公開までが1つのハーネスで完結する。

4. コスト可視化 — 経理AIがトークン使用料を自動集計

経理担当のAI社員が各スタッフAI社員のトークン使用量を円換算しExcel帳簿に記帳する。今回の事例ではPM4300円・ディレクター173円・レビュアー1030円など役割ごとの内訳が出て、合計6,857円で1つのLPが完成した。案件ごとの積み上げ集計も可能で、コスト管理が経営データ化される。

💡 ゆりこの活用メモ

① 「AI社員」の比喩を社内AI推進の説明に転用する 社内でAI活用事例を説明するとき、「サブエージェント」より「担当ごとにAI社員がいて、PMがまとめてる」という方が非エンジニアに伝わりやすい。AI推進部の研修資料の例え話に使える。

② デザイナー役にはデザインシステムを渡すと精度が上がる 動画内でも「デザインシステムを組み込むと同じ依頼でも質が全然変わる」という話があった。ref-briefやgatekeeperで使ってるテイスト語彙集の考え方と同じ。AI社員化するなら役割ごとに専用知識を渡す設計を意識する。

③ コスト可視化の発想を自分のAI活用ログにも 経理AI社員が案件ごとにトークン費用を積み上げ集計してるのは、CORINのAI活用ダッシュボードの「AI活用時間・件数」ログと同じ発想。定量化できると評価材料になる。
