プロンプトの紹介

現在 obisidian  と git が連携されています。これを応用します。
1. tasks といったフォルダを作成します。
2. tasks にファイルが追加され、そのファイルがgit にpush されたら GHA が回ります。
3. GHA内でtasks に書かれているタスク内容とタスクの予定時間からgoogle カレンダーにそのタスクを書き込むといった処理をしたいです。

Obsidian と git の連携

以下拡張機能から連携できます。

https://github.com/Vinzent03/obsidian-git

Google Calendar API の用意

  1. Google Clou にログイン
  2. メニューバーのAPIとサービス をクリック
  3. API とサービスを有効にするをクリック
  4. 「google calendar api」を検索
  5. 「google calendar api」を有効にする
  6. OAuth の認証情報を作成する
  7. 「OAuth クライアントを作成しました」というモーダルが出てくるのでその下の「JSONをダウンロード」でJSONのダウンロード→JSONをcredentials.json として保存

script を用意する

下記コードをコピーして、.github > scripts > sync_calendar.py に配置
なお以下のcreate_calendar_event 関数のcalendar_id は連携するgoogle カレンダーに紐づく gmail を入れる（例:`calendar_id = ‘hogehoge@gmail.com’`）

↓こちらをコピー

今回はカレンダーIDを固定した実装にしていますが、タスクごとにIDを指定して異なるカレンダーに予定を出力する実装にすることも可能です。

Github 上での設定

リポジトリの Settings → Secrets and variables → Actions で以下を設定
GOOGLE_CALENDAR_CREDENTIALS: 1つ目のJSON（google cloud でダウンロードしたjson）
GOOGLE_CALENDAR_TOKEN: 2つ目のJSON（GOOGLE_CALENDAR_TOKEN の取得にて解説）

シークレット変数の設定

GOOGLE_CALENDAR_TOKEN の取得

  1. 以下ファイルをget_token.py　など好きな名前で保存する。
  2. Google Cloud で取得、保存したcredentials.json を実行ファイルと同一の階層に配置する。
  3. ターミナル上で実行する。 `python get_token.py`
    (必要なパッケージはpip でインストールすること)

出力された値をcalendar_token.json として保存(値が取得できればコピーでもOKです。)

タスクを記述する

Obsidianを管理しているルートディレクトリにtasksディレクトリを作成する
tasks 配下に任意のマークダウンファイルを作成する。
例） tasks.md

# 2025-01-25 の予定

## 12:00-13:00 CI の開発
- 場所: おうち

## 14:00-15:30 Cursor 調査
- 場所: スタバ

## 16:00-17:00 Figma 新規デザイン作成
-  場所: おうち

変更内容をGithub 上にアップロードする

Obsidian 上だとcommand+p でコマンド入力できるのでそこからgit など打つとgit commit コマンドが出てくるので commit を行う。同様に git push と入力して push する。

AI要約

松濤VimmerによるObsidianのタスクをGitHub Actions（GHA）経由でGoogleカレンダーに自動同期するCI構築ガイド。Obsidian Git プラグインでMarkdownファイルをGitHubにpushすると、GHAがtasksフォルダ内のmdファイルを検知し、Pythonスクリプトでタスクの日時・タイトル・場所を解析してGoogle Calendar APIで予定を自動登録する仕組み。Google Cloud でのOAuth認証設定、credentials.jsonとtoken取得スクリプトの準備、GitHub Secretsへの設定、calendar-sync.ymlワークフロー定義、sync_calendar.pyの全コードを収録。タスクはMarkdownの見出し形式（## 時間帯 タスク名）で記述する。Cursor Agentによるプロンプト駆動でCI自体を生成した事例でもある。
