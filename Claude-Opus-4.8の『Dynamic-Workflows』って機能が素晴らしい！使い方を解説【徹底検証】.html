📌 ポイント

1. Dynamic Workflows とは — 1指示でサブエージェントを自動生成・並列実行

Claude Opus 4.8に搭載された新機能。1回の指示を投げるだけで、AIが自動的に必要なサブエージェントを「ポコポコ」生成し、それぞれが独立してバックグラウンドで作業を進めてくれる。従来は人間が「文字起こし担当」「編集担当」「QA担当」などサブエージェントを1つずつ手動設計する必要があったが、Dynamic Workflowsはその設計もAIに任せられる。/workflow コマンドで作成済みワークフローを確認でき、実際に15個ものサブエージェントが自動生成されているケースも確認された。

2. 起動方法 — /effort コマンドと自然言語の2通り

Claude Codeのターミナルで /effort コマンドを入力すると、Low / Medium / High / X-High / Ultra Code の5段階が選べる。Ultra Code を選択すると常にDynamic Workflowsが有効になる。もう1つの方法は、プロンプトに「ワークフローで作業して」と自然言語で明示すること。複雑なタスクにはUltra Code、単純タスクはMediumやHighを使い分けるのがコスト的に正解。

3. /goal コマンドとの組み合わせが最強

Dynamic Workflowsと goal コマンドの相性が抜群。/goal を使うと、AIが質問なしで目的に向かって淡々と作業を進め続ける。途中でAIに「これどうする？」と止められずにゴールまで自走してくれるため、複雑なタスクの「中断ロス」がなくなる。特にゲーム制作・LP作成・ディープリサーチなど、多工程が必要なタスクで絶大な効果を発揮する。

4. 適したユースケースと使い分け

Dynamic Workflowsが向くタスク：ディープリサーチ（標準装備）・ゲーム制作・LP作成・動画編集ツール制作・音声入力アプリ開発・家計簿アプリ・拡張機能制作など、複雑で多工程なタスク全般。従来型エージェントチームが向くタスク：再現性・安定性が求められる定型業務（同じワークフローを毎回確実に動かしたい場合）。Dynamic Workflowsは「毎回少し変わる複雑タスク」、従来型は「毎回同じ手順の安定タスク」という使い分けが基本。

5. コスト管理に注意 — Ultra Codeはトークン消費大

Opus 4.8はコストが高く、Ultra Code + Dynamic Workflowsを多用すると週間制限の20%を1日で使うペースになる場合も。単純作業にUltra Codeを使わないこと、エフォート設定を案件に合わせて調整することが必須。セキュリティプラグイン（/plugin install security-guidance@claude-plugin-official）も同時にリリースされており、開発時は必ずインストール推奨。

💡 ゆりこの活用メモ

① CORINスキル・ワークフロー設計にDynamic Workflowsを活用する 新しいスキル（例：/brand-analysis、/wiki-ingest の改良）を作る時、「ワークフローで実装して」と一言添えるだけでサブエージェント設計をAIに丸投げできる。自分でエージェント構成を考える時間が大幅に削減できる。明日のCORIN開発セッションで試してみる。

② ディープリサーチには Dynamic Workflows が標準装備 kemio抹茶やArmillaryの競合調査など、多角的リサーチが必要な場面で /effort → Ultra Code に切り替えるだけで、複数エージェントが並列で調査してくれる。LP制作など成果物への直接アウトプットも一発で依頼可能。

③ Ultra Codeはコストが高い — 使い分けのルールを決める 単純なファイル編集やメモ追記はMedium/High固定。LP・ゲーム・アプリなど「複雑な成果物制作」のときだけUltra Codeをオンにするルールを設ける。
