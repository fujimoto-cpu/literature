📌 ポイント

1. clasp — ローカルとGASクラウドをつなぐブリッジ

claspはローカルのコードをGoogleのクラウドエディタに同期するCLIツール。通常GASはブラウザのエディタにコードを貼り付ける必要があるが、claspを使うとターミナルから clasp push で一発同期できる。Claude Code・Cursor・Codexなど任意のAIコーディングツールと組み合わせることで「AIがコードを書く→そのままGASに反映」という流れが実現する。clasp clone・clasp push・clasp pull がメインコマンド。

2. コンテナバインドスクリプト — フォームと紐付いたGASの作り方

GASには「スタンドアロン（Googleドライブから単独で開く）」と「コンテナバインド（スプレッドシート・フォームから開く）」の2種類がある。フォーム送信をトリガーにしたい場合はコンテナバインドスクリプトが必須。Googleフォームの「スクリプトエディタ」から開いたGASがこれに該当し、onFormSubmit トリガーでフォーム送信イベントを捕捉できる。

3. Claude CodeのPlanモード活用 — 設計→コード生成→自動実行の流れ

Planモードで「Googleフォーム送信→見積書PDF送付の自動化」と入力すると、構成案（フォームとスプレッドシートの作り方・トリガー設定・メール送信先の確認）を提示してくれる。承認後に「Yes, use Auto Mode」でコード全自動生成が走る。ボイスモードで日本語入力することも可能（/config language で日本語設定が必要）。clasp pushコマンドも自動で実行してくれる。

4. セットアップ関数の実行 — GASの初期セットアップとGoogleサービスの権限承認

生成されたコードの setup() 関数をGASエディタで実行すると、スプレッドシートテンプレート・出力フォルダ・フォームのひな形が自動生成される。初回は「Googleドライブへのアクセス権限」「Gmail送信権限」などの承認ダイアログが出るが、1回承認すれば以降は不要。エラーが発生した場合はGASの「実行数」タブでログを確認し、エラー文をそのままClaude Codeに貼り付けて修正を依頼する。

5. 完成系の動作 — フォーム送信からPDF送信まで約数秒

公開設定したGoogleフォームに顧客情報・商品・数量を入力して送信すると、スプレッドシートに見積書が自動生成され、PDFが添付されたメールが顧客アドレスに届く。拡張は「フォルダIDを渡して特定フォルダに保存」「メール文面を変更」「商品マスタをスプレッドシートで管理」など全てClaude Codeへの追加指示で対応可能。

💡 ゆりこの活用メモ

① 見積書・品質表示・提出物の自動生成に即応用できる Googleフォームに案件情報を入れたら見積書PDFがクライアントに自動送信される仕組みを、KONNEKT案件の受付フローに導入できる。品質表示タグ生成ツール（青木さん依頼）でも同様のフォーム→GAS→PDF出力パターンが使える。明日、既存の品質表示スキルでGAS版の構成を検討してみる。

② clasp + Claude Code CLIをローカルにセットアップしておく npm install -g @google/clasp でインストール後、clasp login でGoogleアカウント連携。一度設定すれば以降はClaude CodeがGASコードの生成〜反映を全自動で行う。デスクトップアプリでも動作する。今週中にインストールして試す。

③ GASエラーはそのままClaude Codeに貼り付けるだけ GASエディタの「実行数」タブ→エラーログをコピー→Claude Codeに貼り付けて「このエラーを直して」と言うだけで修正コードが生成されclasp pushまで自動で完了する。デバッグのハードルが極めて低い。
