📌 ポイント

1. CLAUDE.md＝クライアント専用マニュアルを育てる

案件ごとのフォルダに CLAUDE.md を作り、トンマナ・禁止ワード・構成ルール・過去の修正依頼を全て記録しておく。Claude Code はフォルダを開くたびにこのファイルを自動参照するため、案件を重ねるほど「専属スタッフ化」する。最初から完璧でなくていい。フィードバックを都度追記していく仕組みが肝。

2. 5ジャンルの特性と単価感

  • ライティング：案件数ダントツ多・1記事1,000〜6,000円・初心者最初の1件向け
  • Web制作/LP：1件3〜5万円（直取引で10〜20万）・ライティングの次ステップ
  • リサーチ代行（eBay等）：月額継続になりやすい・穴場ジャンル・1件5,000〜1万円
  • 画像生成：Claude Code でプロンプト作成→Gemini で生成のハイブリッド方式・1枚300〜3,000円
  • 法人案件：月額20〜30万/社・継続前提・単価の上限がない

3. 法人案件を取る5ステップ

①クラウドワークスで個人案件3〜5件こなし納品実績を作る → ②Claude Codeでポートフォリオサイト作成 → ③SNSで実績・仕組みを発信して「探される側」に → ④中小企業・個人事業主に直接DMで提案（強み＋相手メリットを簡潔に） → ⑤最初の1社は相場より低く、2社目以降は値上げ。対応範囲と納品条件は最初に明確化。

4. 使い方の注意点3つ

① ファイル編集の確認設定は必ず「デフォルトモード」に（accept-edits-on になっていたら Shift+Tab で戻す）。② 1タスク1会話ルールを守る（長く続けると文脈崩れ・文体ズレが起きやすい）。③ プラン選びはAPI従量課金でなくProまたはMaxサブスクで（毎日使う場合は100ドルのMaxプランが安心）。

💡 ゆりこの活用メモ

① KONNEKT社内のAI導入推進に応用 CLAUDE.md の「クライアント専用ルール蓄積」の仕組みは、社内の案件ごとのAIワークフロー標準化にそのまま使える。案件フォルダにCLAUDE.mdを作り、クライアントのトンマナ・NGワードを入れておくことで、誰でも同品質の出力が出せる体制をつくれる。明日の朝、既存案件フォルダの1つにCLAUDE.mdを試作してみる。

② 画像生成案件のハイブリッド方式を即導入 Claude Codeでプロンプト作成→Geminiで生成という分業フローは、バナー・サムネ制作に今すぐ使える。1案件でデモを作って社内に共有する。
