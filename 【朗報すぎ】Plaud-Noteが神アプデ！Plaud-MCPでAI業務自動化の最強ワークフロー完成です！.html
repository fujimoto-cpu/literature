📝 要約

🎯 ボイスレコーダー「Plaud Note」に、録音データをMCP経由でChatGPT・Claude等のAIへ直結する「Plaud MCP」機能が無料追加。録音→要約→議事録・メール・タスク登録までを丸ごと自動化できるようになった。

🗺️ 全体像

flowchart TD

    C --> D[メール作成・タスク化・Notion転記まで自動実行]

📌 ポイント

1. Plaud MCP＝録音データとAIを橋渡しする無料アップデート

MCP（Model Context Protocol）はAIツールと外部サービスをつなぐ共通規格。Plaud MCPにより、Claude・ChatGPTに加えCursor・Windsurf等の開発者向けツールからも、Plaudに溜まった「録音一覧」「個別録音の詳細」「AI要約・アクション項目」「話者ラベル付き全文文字起こし」の4種類のデータを直接読み取れるようになる。既存デバイスユーザーは追加料金ゼロで今日から使える。

2. 曖昧な指示でも該当の会議データをAIが探し出す

「〇〇会議の要点まとめて」のような曖昧な聞き方でも、AIが該当の録音を自分で検索して読み込み、回答してくれる。過去の全会議録音がAIにとって検索可能なデータベースに変わるイメージ。

3. 要約だけでなく複数ツールをまたいだ業務自動化まで可能

録音データをもとに「フォローアップメール作成」「競合比較表作成」「タスクを抜き出してNotionのチームスペースに日付入りで新規ページ追加」といった、複数ツールをまたぐ作業までAIに一括で指示できる。

4. 導入前に確認すべき2つの注意点

①日本アカウントの場合、データはAWS日本リージョンに保存される（海外サーバーではないが、クラウド保存自体を規定で制限する企業は事前確認が必要）。②Plaud MCP自体がやるのは「録音データをAIに渡す」ところまでで、Asanaへのタスク作成やHubSpot更新などの実行は、各サービス側との連携を別途つなぐ必要がある（Plaud単体で全アプリを操作する魔法の杖ではない）。

💡 ゆりこの活用メモ

① 会議の録音→議事メモ化フローと比較して検討する 現状は00_🏢 company/voice/（🔧 Faster Whisperベース）で文字起こし→議事メモ化しているが、Plaud MCPは「録音デバイス→AI直結」まで1本化できる点が違う。機密性の高い社内会議はAWS日本保存とはいえクラウド送信になるため、社内規定を確認してから検討する。
