📝 要約

🎯 Claude Code Routinesは「クラウド上でClaude Codeを自動スケジュール実行できるサービス」。5つの設定項目だけで定期ルーティン・Slack日報・会議前集計などを完全自動化できる。

🗺️ 全体像

    A[Claude関連サービス全体] --> B[チャット型\nClaude.ai / ChatGPT等]
    A --> C[エージェント型]
    C --> D[汎用型\nCowork]
    C --> E[コーディング用\nClaude Code]
    E --> F[PC上で動くClaude Code\n手元ファイル読み書き]
    E --> G[クラウドで動くClaude Code\nブラウザ経由・並列実行]

    H --> I[5設定項目\nプロンプト/コネクタ\nリポジトリ/トリガー/環境]

📌 ポイント

1. サービス全体の分類 — チャット型 vs エージェント型 vs コーディング型

Anthropicのサービスは「チャット型（Claude.ai）」「汎用エージェント型（Cowork）」「コーディング用エージェント型（Claude Code）」の3系統に分かれる。Claude Codeはさらに「PC上で動く版」と「クラウドで動く版」に分かれており、Routinesはそのクラウド版を自動実行できるようにしたもの。

2. 5つの設定項目だけで自動化が完成する

Routinesで必要な設定は①プロンプト（何をするか）②コネクタ（Slack・カレンダー・タスク管理等との連携）③リポジトリ（GitHubリポジトリの指定）④トリガー（スケジュール/API/GitHub）⑤環境（仮想マシンの設定・ネットワーク・環境変数・セットアップスクリプト）の5つのみ。これだけでManagedAgentを自前構築するよりはるかに低コストで自動化が実現できる。

3. 3種類のトリガー — スケジュール・API・GitHub

スケジュールは「毎週火曜9時に実行」などの定期実行。APIは専用URLと認証キーが発行され、外部サービスや手元PCからHTTPリクエストを送るだけでルーティンを起動できる。GitHubトリガーはPR発行・マージ・特定ブランチ名など実務上よく使う条件でフィルタリング可能。3つは組み合わせて使える。

4. 環境設定でセキュリティを担保できる

仮想マシンのネットワークアクセスを「このサーバーのみ」に絞ることで、意図しない情報漏洩を防げる。環境変数もルーティンごとに独立して設定でき、APIキー等をセキュアに扱える。Coworkには存在しなかったこの粒度のセキュリティ設定が、Routinesの大きな優位点。

5. コーディング以外の業務ルーティンにも使える

Slackのその日の発言ログをまとめて日報チャンネルに投稿・Slackの全チャンネルを読んで自分宛の重要メンションを通知・定例会議前にKPIを集計してレポートを自動生成、などが実現可能。オフィスワーカーが日常的にやっている定型作業の多くをRoutinesに乗せられる。

💡 ゆりこの活用メモ

① CORINのルーティン自動化への応用 現在Claude Codeで手動実行しているohayo・eod・x-ai-trendsなどのスキルをRoutinesのスケジュールトリガーに移行すれば、完全無人で定期実行できる。まずSlack日報（/eodのSlack通知版）を試す。

② Slack監視の自動化 コネクタ（Slack）＋スケジュールで「自分宛メンションを毎朝集約して通知」するルーティンを作れば、メッセージ見落としゼロになる。IP週次レポートやX監視も同様に移行候補。
