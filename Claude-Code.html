📋 Claude Code — 概要

AnthropicのCLIベースAIコーディング・業務自動化ツール。ターミナルから起動し、ファイルの読み書き・コマンド実行・Web検索を自律的にこなす。.claude フォルダ（CLAUDE.md / settings.json / rules/ / skills/ / agents/）を設計することで「AIの頭の中」を固定し、毎セッション同じ前提で動作させられるのが最大の特徴。

うまくいった使い方・主要な知見

  • .claudeフォルダの5ステップ設計：settings.json → CLAUDE.md → rules/ → skills/ → agents/ の順で構築することで、再現性の高いAI環境を実現
  • mistakes.md（やらかしログ）：過去のミスを記録することで再発率を大幅に低減。AIは記憶がリセットされるからこそ有効
  • 1人開発チームの構成：フック（自動実行）＋カスタムコマンド（ワンコマンド化）＋サブエージェント（役割分担）の3機能を組み合わせる
  • Obsidianとの連携でAI外部脳：raw/wiki/CLAUDE.mdの3層＋Ingest/Compile/Query/Lintの4サイクルで知識ベースを構築
  • 非エンジニアの活用：スキルファイルに「専門家の思考」を入れれば業種を問わず活用可能（投資シミュレーター・経費自動化など）

補足

Desktop版ではVisual Diff Review・セッション並列実行・Bypass Permissions（ヨロモード）・スキル共有4レベルなどの機能が追加されている。Coworkと組み合わせることで1日4時間削減できるワークフロー構築も可能。
