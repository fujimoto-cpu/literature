📝 要約

🎯 SlackにClaude（Claude Tag）を入れると、チャンネルの会話文脈を踏まえてAIが動く。Teamsプランが前提で、初月無料クレジットの使い方・自動返信オフ・承認ポイントの設計が運用の肝。

📌 ポイント

1. 前提と用語 — Claude Tag / Claude Code / MCP

Teamsプランの2アカウントから（動画では月50ドル程度と紹介）。Claude TagはSlack内で担当仕分けをしてAIが必要な所でサポートする機能、Claude Codeは開発向きの作業版、MCPはSlackと外部ツールをつなぐ接続口、と区別して説明している。

2. コスト設計 — 初月の無料クレジットで選別する

初月は2500ドル分が無料（動画の画面では75ドル使用で残り2425ドル）。初月に試して必要な用途だけ残し、2か月目以降はチャンネルごとに上限を付けて使用量を管理する。チャンネルの設定で自動返信をオフにし、メンションした時だけ返信させればクレジットの無駄遣いを防げる。

3. 実例 — 自動要約・サイト修正・議事録

ZapierでスプレッドシートからSlackに流れる株データを、Claudeが毎日「昨日との差分」で要約。HTMLサイトの修正を、非エンジニアがSlack上で指示→ビフォーアフターのプレビュー確認→GitHubでPR→公開まで完結。Google Meet／Zoomの議事録が会議の数分後にSlackへ自動投稿され、フォーマットも指定できる。

4. ガバナンス — どこまで任せ、どこで人が承認するか

最初に、どのチャンネルで使うか、どの情報・ツールにアクセスさせるか、どこまで自動化して人間の承認を挟むかを決める。コントロールしないと勝手に投稿したり、書いてほしくないコードまで書くリスクがある。

💡 ゆりこの活用メモ

① 社内AI推進で「無料の初月に選別する」運用を提案する 課金プランを試す場合は、初月に用途を絞り、2か月目から上限と自動返信オフを入れる設計にする。

② Slack運用の承認ポイントを先に言語化する 自動化する範囲と人が確認する場所を1枚にして、導入前に共有する。
