■ 𝗰𝗹𝗮𝘂𝗱𝗲-𝗼𝗯𝘀𝗶𝗱𝗶𝗮𝗻 とは何か

claude-obsidianは、GitHub上で公開されているオープンソースのClaude Codeプラグインです（MIT License、GitHub: AgriciDaniel/claude-obsidian、1.9kスター）。

Andrej Karpathy氏（OpenAI創設メンバー、元Tesla AI部門ディレクター）が提唱した「LLM Wiki」パターンを実装したもので、一言でいうと「知識が複利で増えるObsidian Vault」を作るツールです。

従来のAI × ノートツールの問題点は、毎回セッションが切れるとコンテキストがリセットされること。claude-obsidianはこの問題を根本から解決します。

ソースを投げれば、Claudeがそれを読み込み、エンティティと概念を抽出し、相互参照を更新し、構造化されたObsidian Vaultに自動でファイリングする。1つの記事を入れるだけで8〜15の相互リンクされたWikiページが生成されます。

つまり、使えば使うほどVaultが賢くなる。知識が「複利」で積み上がっていく仕組みです。

■ 𝗰𝗹𝗮𝘂𝗱𝗲-𝗼𝗯𝘀𝗶𝗱𝗶𝗮𝗻 の始め方

必要なもの：

・Obsidian（デスクトップ版）

・Node.js 18以上

・Claude Code（CLIまたはデスクトップアプリ）

インストールは3つの方法があります。

【方法1】Vault Clone（推奨・2分で完了）

```

git clone https://github.com/AgriciDaniel/claude-obsidian

cd claude-obsidian

bash bin/setup-vault.sh

```

クローンしたフォルダをObsidianで開くだけ。これが最も簡単です。

【方法2】Claude Codeプラグインとして追加

```

claude plugin marketplace add AgriciDaniel/claude-obsidian

claude plugin install claude-obsidian@claude-obsidian-marketplace

```

【方法3】既存のVaultに導入

GitHubリポジトリから `WIKI.md` をコピーして自分のVaultに配置し、Claudeにセットアップを指示するだけ。

どの方法でも、最初に `/wiki` コマンドを実行するとVaultの基本構造がスキャフォールドされます。

■ /𝘄𝗶𝗸𝗶 コマンド── Vault の骨格を一発構築

`/wiki` は最初に実行するコマンドです。

これを打つと、Claudeが以下の構造を自動生成します：

・`wiki/index.md` — マスターカタログ（全ページの目次）

・`wiki/hot.md` — ホットキャッシュ（最近のコンテキストを保持）

・ドメイン別のサブインデックス

・`.raw/` フォルダ — 取り込んだ原文の保管場所

特に重要なのが `hot.md` と `index.md` の2ファイル。

`hot.md` はセッション間のコンテキストを自動で保持するファイルです。通常のAIチャットでは会話が切れると全部忘れますが、claude-obsidianでは `hot.md` に最近の作業内容が自動キャッシュされるため、次のセッションでも「さっきの続き」から始められます。

`index.md` はVault全体のマスターカタログ。Claudeはまずこのファイルを読んで、どのページに何が書いてあるかを把握します。全ページを毎回読み込むのではなく、インデックスから必要なページだけを選択的にロードするため、トークンコストを大幅に節約できます。

■ 𝟯つのコアコマンド── /𝘀𝗮𝘃𝗲 /𝗮𝘂𝘁𝗼𝗿𝗲𝘀𝗲𝗮𝗿𝗰𝗵 /𝗰𝗮𝗻𝘃𝗮𝘀

claude-obsidianの日常的な操作は、主に3つのコマンドで回ります。

【/save】会話をWikiノートに変換

Claudeとの会話で価値のある情報が出たら `/save` を打つだけ。Claudeが会話全体を読み、キーアイデアを抽出し、適切にフォーマットされたWikiページを作成し、既存ページへのWikilinkを自動生成し、index.mdを更新します。

`/save プロンプトエンジニアリング` のように名前を指定することも可能です。

【/autoresearch】自律リサーチループ

`/autoresearch [トピック]` を実行すると、Claudeがそのトピックについて自律的にリサーチを行い、結果をWikiページとしてVaultに蓄積します。

例えば `/autoresearch RAG最新手法` と打てば、RAGに関する知識がVaultに体系的に追加されていきます。

【/canvas】ビジュアルナレッジマップ

Obsidianのキャンバス機能と連携し、知識の視覚的なマッピングを行います。12のビジュアルテンプレートと6つのレイアウトアルゴリズムが用意されており、プレゼンテーション、フローチャート、ナレッジグラフなどを自動生成できます。

■ 毎日のインジェストループ── .𝗿𝗮𝘄/ フォルダの使い方

claude-obsidianの真価は「日常的な情報の取り込み」にあります。

やり方はシンプル：

1. 気になった記事、論文、メモを `.raw/` フォルダに放り込む

2. `ingest [ファイル名]` コマンドを実行

3. Claudeが自動で読み込み、要約し、概念を抽出し、既存のWikiページと相互リンクを張る

複数ファイルを一括処理したい場合は `ingest all of these` で一括取り込みが可能。このとき、ファイル間の相互参照も自動で生成されます。

さらに便利なのが `lint the wiki` コマンド。これはVault全体のヘルスチェックを実行し、以下を検出します：

・壊れたリンク（デッドリンク）

・孤立したページ（どこからもリンクされていないノート）

・知識のギャップ（言及されているが詳細ページがないトピック）

・古くなった記述

つまり、Vaultの「メンテナンス」までAIが自動でやってくれるわけです。

■ コスト効率の設計── なぜトークンを無駄にしない

「AI × ノートツール」で多くの人が心配するのがAPIコストです。

claude-obsidianはここも巧みに設計されています。

仕組みは3つ：

・`hot.md` — 直近のコンテキストだけをキャッシュし、毎回全履歴を読まない

・`index.md` — マスターカタログから必要なページだけを選択的にロード

・ドメイン別サブインデックス — 関連する領域のページだけにアクセスを限定

たとえばプログラミングについて質問した場合、Claudeはindex.mdを見て「programming」関連のサブインデックスだけを読み、そこからさらに必要なページだけを開く。Vault全体が1000ページあっても、実際に読み込むのは10〜20ページ程度で済みます。

これにより、Vaultが巨大化してもトークンコストが線形に増加しない設計になっています。

■ 𝟭ヶ月後のグラフビュー── 知識が「見える」瞬間

@defileo氏の投稿で最も反響があったのが、1ヶ月間運用した後のObsidianグラフビューのスクリーンショットです。

ノード（概念）が色分けされ、それぞれが相互にリンクで繋がっている。手動では絶対に作れない、密度の高いナレッジグラフが自動的に形成されています。

これが「知識が複利で増える」の意味です。

最初の1週間はページ数も少なく、リンクもまばら。しかし2週間、3週間と続けるうちに、新しく入れた情報が既存の知識と自動的に結びつき、ネットワーク効果が加速する。4週間目には「自分が何を知っているか」がグラフで一望できる状態になります。

■ 実際の活用シーン

claude-obsidianは以下のような場面で特に威力を発揮します：

・論文や技術記事を日常的に読む研究者・エンジニア

→ 読んだ内容が自動で体系化され、後から「あの論文のあの概念」をすぐ引ける

・複数プロジェクトを並行して進めるマネージャー

→ プロジェクト間の知識がクロスリファレンスされ、意思決定の質が上がる

・学習中のトピックを深掘りしたい人

→ /autoresearchで自律的にリサーチ、知識の穴を自動検出

・Obsidianを使っているが「メモが散らばる問題」を抱えている人

→ AI が自動でリンクを張り、整理してくれるため、手動メンテナンスが不要に

重要なのは、これがObsidianのローカルファイル（Markdown）で動いている点。データは全て自分のマシンに残り、クラウドに依存しません。

■ マルチモデル対応── Claude以外でも動く

claude-obsidianという名前ですが、実はClaude以外のモデルでも動作します。

対応モデル：

・Claude（推奨）

・Gemini

・Codex

・Cursor

・Windsurf

プロバイダーに縛られない設計のため、将来的にモデルを切り替えても蓄積した知識はそのまま使えます。

■ まとめ── 「メモを溜めるだけ」を卒業する

claude-obsidianが解決する問題は明確です。

従来のObsidian運用：

メモを書く → リンクを手動で貼る → 面倒で続かない → ノートが散らばる → 結局検索頼み

claude-obsidian導入後：

ソースを .raw/ に入れる → ingestする → 自動でWikiページ生成・相互リンク・インデックス更新 → 使うほど賢くなるVaultが育つ

しかもオープンソース（MIT License）で無料。GitHubスター1.9kが示す通り、海外のObsidianコミュニティではすでに定番ツールになりつつあります。

「AIセカンド脳」を始めたいなら、最もハードルが低く、最もリターンが大きい選択肢の1つです。

今すぐ試す手順：

1. https://github.com/AgriciDaniel/claude-obsidian をクローン

2. `bash bin/setup-vault.sh` を実行

3. Obsidianでフォルダを開く

4. `/wiki` でVaultを初期化

5. 好きな記事を `.raw/` に入れて `ingest` する

5分で始められます。

どうでしたか。

記事を書いていくうちに自分でもこうすれば、うまく回せるしコストも削減できるのかってめちゃくちゃ勉強になりました。

自動化レベルまで運用を極めるのは難しいですが、極めた人を参考にすることはできるのでどんどん学んでいきたいです！

📌 ポイント

1. claude-obsidian = Karpathy LLM Wikiの実装版

AgriciDaniel/claude-obsidian（GitHub ⭐ 1.9k・MIT License）。1記事を入れると 8〜15の相互リンクされたWikiページが自動生成される。「使えば使うほどVaultが賢くなる＝知識が複利で積み上がる」が中心思想。

2. 3層キャッシュでトークンコストを線形に増やさない設計

①hot.md（直近コンテキストキャッシュ）②index.md（マスターカタログ）③ドメイン別サブインデックス、の3層で必要なページだけを選択ロード。Vault 1,000ページでも実読み込みは10〜20ページに抑える。

3. 5つのコアコマンド

/wiki（骨格構築）／ /save（会話→Wikiノート変換）／ /autoresearch [トピック]（自律リサーチループ）／ /canvas（ビジュアルナレッジマップ・12テンプレ×6レイアウト）／ ingest [ファイル]（.raw/から取り込み）＋ lint the wiki（健康診断）。

4. 1ヶ月後のグラフビューが「複利の証拠」

1週間目はリンクまばら → 4週間目には密度の高いナレッジグラフが自動形成。手動では絶対作れない。「自分が何を知っているか」を視覚的に俯瞰できる状態に到達する。

5. マルチモデル対応＆ローカルファースト

Claude推奨だが Gemini / Codex / Cursor / Windsurf でも動作。プロバイダー縛りなし。データはローカルのMarkdownに残り、クラウド依存しない。
