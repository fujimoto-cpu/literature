🎯 claude-code の新機能「Dynamic Workflows」を解説。最大1,000体のAIエージェントを並列で自律起動し、長時間・高精度な複合タスク（リサーチ・開発・戦略）を放置だけで完遂できる仕組みとその始め方。

📌 ポイント

1. Dynamic Workflows — 「分割・並列・統合」で放置完遂

2026年5月末、Claude Opus 4.8と同時リリース。依頼したらClaudeが自ら複数のAIエージェントを生成してタスクを分割し、並列実行して最後に統合する。最大1,000体・同時16体まで並列可能。「財務戦略を考えて」と伝えたら24体が走り8分で完成した事例も。30分〜1時間放置するだけでレポートや実装が完成する。

2. プロンプト → コンテキスト → ハーネスという進化の流れ

AI活用は「プロンプトエンジニアリング（役割・形式指定）」→「コンテキスト（情報量の最大化）」→「ハーネス（どのツールをどう繋いでどう動かすか）」と進化してきた。モデルの性能よりも「ハーネス設計（ループ・ガードレール・権限・ツール接続）」の方が成果を左右する時代になった。prompt-engineeringはまだ有効だが、AIワークフロー全体設計が主役。

3. 敵対レビュー（GAN的手法）で精度を高める

Dynamic Workflows内部では「あえて全否定する性格の悪いエージェント」を1体混ぜることで成果物の精度を上げている。GAN（敵対的生成ネットワーク）と同じ古典的な手法をマルチエージェントで実装。コンテキスト収集→行動→自己検証→ループ、というサイクルを繰り返すことで精度が保たれる。

4. 使い方は驚くほど簡単 — デスクトップアプリで「賢い」モード選択だけ

デスクトップアプリ最新版を開き、右下のモデル選択で「ウルトラコード」または「賢い」設定にして入力するだけで自動でDynamic Workflowsが起動する。ターミナル使用時は claude --effort max で起動可能。注意点：トークン消費が非常に多いため、簡単なタスクには使わない（複雑なリサーチ・開発専用）。

5. ハーネス設計を自分で作りたいなら4ステップ

① CLAUDE.mdをしっかり定義する → ② /agent でサーチ用・実装用などの専用エージェントを作る → ③ スキルとして定型化する → ④ フック（エージェント終了時のトリガー）でレビューを自動実行する。Dynamic Workflowsが内部でやっていることをあえて手動設計して理解したい人向けの学習ステップ。

💡 ゆりこの活用メモ

① 次回Armillary.やKEMIOの大型リサーチはウルトラコードで丸投げしてみる 「競合ブランド10社分析して」「26AWのムードボード用トレンド深掘りして」のような複合リサーチを、デスクトップアプリの「賢い」モードで入力して放置する。30分後に戻ってくるだけで良い。トークン消費は多いが、5時間かかるリサーチが8分になる価値と天秤にかけて使う。

② AI推進の社内資料に「プロンプト→コンテキスト→ハーネス」の進化軸を使う 「プロンプトだけ覚えても不十分」という文脈で、この3段階進化の図を使うと説得力が増す。青木さん向け品質表示タグツールのような「どのツールをどう繋ぐか」の設計が今後の核心と伝えられる。
