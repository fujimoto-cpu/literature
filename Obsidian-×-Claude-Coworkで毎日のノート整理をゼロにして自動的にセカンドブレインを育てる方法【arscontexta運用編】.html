📝 要約

🎯 Earth Contextaプラグインの第3弾運用編。Claude Coworkのスケジュールタスク機能を使って、ObsidianのVaultを毎日自動でセカンドブレインに取り込む仕組みを4ステップで構築する方法。

🗺️ 全体像

flowchart TD
    A[ステップ1: 準備\nCoworkプロジェクト作成] --> B[ステップ2: PC側\nClaude Codeでテンプレ書き換え]
    B --> C[ステップ3: Cowork側\nプロンプトを再カスタマイズ\n→スケジュール登録]
    C --> D[ステップ4: 初回実行\n権限許可+タイムスタンプ記録]

📌 ポイント

1. 毎日の自動取り込み — Coworkスケジュールタスクが唯一の選択肢

Claude Codeの他モード（Projects等）はセッション中しか動かないか、VaultのMDファイルを直接編集できないという制約がある。毎日決まった時間に自律実行でき、かつObsidianのファイルを直接読み書きできるのはCowork（Claude Cowork）のスケジュールタスク機能のみ。PCが起動していなくても、起動した瞬間に「見逃し実行」として1回だけ追いかけ処理が走る設計になっている。

2. 4ステップ構成 — コピペだけで完成する

Step1: ObsidianのVaultルートフォルダをマウントしたCoworkプロジェクトを用意（既存でもOK）。Step2: GitHub GISTからbatchテンプレートをDLし、Claude Code（Claudia）に渡して自分のPC環境（Vaultパス・除外フォルダ）に書き換えてもらう。Step3: そのプロンプトをCoworkプロジェクト内でさらに書き換えてもらい、スケジュールタスク（毎日22時等）として登録。Step4: 「今すぐ実行」で権限許可＋初回タイムスタンプ記録。これで自動化完了。コードは一行も書かない。

3. タイムスタンプ方式 — 差分のみ処理で軽量

仕組みの核心は「処理した時刻を記録→次回はその時刻以降に作成・更新されたファイルだけを対象にする」差分処理方式。初回実行時は処理対象0件となるが、それが正常動作。以降は毎日の新規・更新ファイルのみEarth Contextaパイプライン（アトミックノート分解→グラフ接続→整合性チェック）に流れる。

4. Earth Contexta 3部作の完結 — 概念・マイグレ・運用がセット

第1弾（概念編）: Earth ContextaプラグインでObsidianノートが自動でつながる仕組みの解説。第2弾（マイグレーション編）: 過去の何百・何千ノートをAIに丸投げしてグラフ化。今回の第3弾（運用編）: 設定後を毎日手放しで回す自動化。3本セットで初めてセカンドブレインが「成長し続ける」状態になる。
