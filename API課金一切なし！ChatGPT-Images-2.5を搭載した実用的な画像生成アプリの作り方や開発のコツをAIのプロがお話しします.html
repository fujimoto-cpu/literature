📝 要約

🎯 Codex App Serverでサブスク内のChatGPT画像生成を呼び出し、API課金ゼロでバナー・サムネを3案並行生成する自作アプリ「Codex Image Studio」の作り方と開発のコツ。

1. API課金なしの仕組み — Codex App Server

Codexをアプリの裏側に載せると、ChatGPTのサブスク枠内でAI機能入りのWebアプリが作れる。従量課金APIは高いので、余っているサブスク枠を使えるのが最大のメリット。自分用ツール向き。注意点として、画質（high/low/auto）をプログラム側で固定できずautoやlowになり、ChatGPT本体で作るより画質が落ちる場合がある。本格運用ならAPI接続が選択肢。

2. アプリの機能

用途（バナー等）・比率（16:9）・必ず入れる文字・配色を指定し、参考画像に役割（配色/ロゴ/人物）を振れる。「制作レシピ」で裏側のプロンプトをセットし、3案を並行生成。生成後にCodexが検品して点数（例: 95点）を付け、範囲指定の部分修正や別サイズへの展開、書き出し（PNG/JPEG/WebP）もできる。履歴・生成に使った拡張プロンプトも残る。データはローカルフォルダに溜まる。

3. 作り方のコツ — 役割分担

要件はAIとの壁打ちで詰めてから実装させる。実装はCodex、UI/UXデザインはClaude Codeと使い分ける。Codex単体だとデザインが「Codex感」で微妙だったため、動くアプリに対してClaude Codeでデザイン案を複数作らせ、良いものを本番適用した。デザインシステム（コーポレートカラー基調）を用意して毎回使うのも効く。

💡 ゆりこの活用メモ

① デザインはClaude・実装は別ツールで分業 見た目だけ別パターンを作らせて選ぶ流れは、ゆりこの制作スピード課題にそのまま使える。次にツールを作る時は先にデザイン案を3つ出させる。

② 「3案並行＋検品点数」を自分の制作フローに バナー・SNS素材をたたき3案で出し、AI検品で粗を潰してから自分が仕上げる形にすると、デザインに時間がかかりすぎる課題を削れる。
