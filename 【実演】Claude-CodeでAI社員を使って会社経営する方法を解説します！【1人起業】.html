  4. 動かしてPDCA：実際に動かして「足りなかった情報」（実績・強み等）を project.md / 各CLAUDE.mdに追記して育てる

  • Skills（スキルズ）: 定型業務をマニュアル化→一言で起動。各担当ごとに集約
  • 定期実行（Routines）: デスクトップアプリの Routines 機能。Local＝ファイル操作可（PC ON必須）／Remote＝クラウド実行（ファイル操作不可）。月曜朝の案件リサーチや毎朝のGoogleカレンダー＋Slack整理を自動化
  • エージェントチーム機能（実験的）: .claude/settings.json で有効化＋ .claude/agents/ に担当登録すると、会社用フォルダから一括指示で各担当が連携。ただし消費量が大きいので並列・複雑タスクのみ推奨。Claude Code v2.1.3 以降が必要

料金とリスク

  • **MAX 5X（月100／約1.5万円）を強く推奨∗∗。Proプラン（20）だと並列で即制限に到達。2026年4月にAnthropicがProでClaude Code無効化をテストした経緯もあり、長期運用するならMAX5X以上が安心。人件費（月30万円相当）と比べれば1/10以下
  • セキュリティ: ①CLAUDE.md ＋ settings.local.json で操作範囲を制限（願い＋仕組みのハイブリッド）／②機密・APIキーはチャットやファイルに置かず環境変数管理／③Mac/Linuxはサンドボックス活用
  • 使用量節約: エージェントチームは温存しつつ通常はスキル＋単独担当で済ませる。複雑判断はOpus、定型はSonnetなど 担当別にモデル切替
  • 障害対策: 2026年3月のClaude大型障害事例あり。「丸投げ依存」ではなく「自分の作業を肩代わりさせる」スタンスを維持し、Codex／Cursor／Antigravity 等の他ツールでも動かせる状態を作る

結論メッセージ

Claude Code で会社の仕組みを作ること＝売上が立つこと、ではない。仕組み化で空いた時間をスキル磨きや新しい挑戦に投資する ことが本質的価値。みんなが「怖いから動かない」状態だからこそ、一歩踏み出した人がリードできる。
