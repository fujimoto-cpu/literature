📝 要約

🎯 「DESIGN.md」を1ファイルプロジェクトに置くだけで、クロードコードやCursorなどのAIコーディングエージェントが、Apple・Notion・Linear・Stripe・Figmaといった有名ブランドのデザインシステムを”忠実に再現したUI”を生成できるようになる、というGoogle発のDESIGN.mdスペック準拠の無料コレクションサイト。

📂 何が手に入るか

71件のDESIGN.mdファイルが公開されている。Apple / Notion / Linear / Stripe / Figma / Claude / Cursor / Vercel / Supabase / Shopify / Spotify / Nike / Tesla / BMW / Ferrari / WIRED / The Verge など、各ブランドの「カラー・タイポグラフィ・余白・モーション・写真ディレクション」が production grade で言語化されている。

🎨 なぜ「表面的じゃない」か

単なるカラーコード集ではない。例えばClaudeは「warm terracotta accent + clean editorial layout」、Linearは「ultra-minimal + precise + purple accent」、Teslaは「radical subtraction + full-viewport photography + near-zero UI」のように、ブランドの哲学・トーン・空間設計の流儀まで記述されている。AIがUIを生成するときに「らしさ」が出る。

🛠️ 使い方フロー

  1. 気に入ったブランドのDESIGN.mdをDL
  2. プロジェクト直下に配置（CLAUDE.md / AGENTS.md と同居）
  3. Claude Code / Cursor / Lovableなどのエージェントが自動参照してUI生成 Google発の “DESIGN.md spec” に準拠しているため、対応エージェントなら追加プロンプトなしで効く。

💡 Creative Direction Note

① 「ブランド分析HTMLレポート」の自動化に直結する ゆりこが毎週やってる /brand-analysis スキル（Armillary./MEADOW./kemio含む）に、このDESIGN.md形式を採用すると「分析→AI生成UI」までシームレスに繋がる。明日の朝、まずClaudeのDESIGN.mdをDLして、現在のbrand-analysis出力フォーマットと差分を取る。

② Armillary. / MEADOW.のDESIGN.mdを自作する 26AW提案 or MEADOW. Magazineの一部として、自社ブランド版DESIGN.mdを納品物に加える。クライアント（コネクト案件）にも応用可。「ブランドガイドライン」より遥かにAI時代適合度が高い。来週前半、Armillary.26SSの全Shopify/IG/PPTX資産からDESIGN.md v1をドラフトする（半日タスク）。

③ コネクト社内のAI推進ネタにもなる 全社員Cowork講習の次フェーズ素材として、「DESIGN.md+Claude Code でLP1枚を30分で組む」デモが組める。デザイナーじゃない人がブランドトーン維持してUI触れるようになる、というインパクト。
