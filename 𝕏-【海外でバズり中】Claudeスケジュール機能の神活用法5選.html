【海外でバズり中】Claude”スケジュール機能”の神活用法5選 星川ユウヤ / 現場で使えるAI @starriver0513 海外のSNSマーケターの間で今、Claudeのスケジュール機能を使った自動化がバズっています。 「寝てる間にSNS運用の8割が終わる」 ↑これ、もう海外では当たり前になりつつあります。 僕は今、毎朝起きたら競合の動向レポートが1本、今週の投稿パフォーマンス分析が1本、Coworkが自動で作って待っている状態です。 「スケジュールタスクって何？」という人のために一言で説明すると、Coworkに「毎朝9時にこれやって」と設定しておくと、本当に毎朝9時に自動で実行してくれる機能です。2026年2月のアップデートで追加されました。 設定は /schedule とチャット欄に打つだけです。頻度は毎時・毎日・毎週・平日のみ・手動、から選べます。コードは一切書きません。 注意点として、このスケジュール機能はデスクトップ版の「Claude Cowork」と「Claude code」でしか使えません。チャット版では使えませんのでご注意を！ Claude Coworkについては こちらの記事で分かりやすく解説しました👇 https://x.com/starriver0513/status/2032769241980743895?s=20 Claude codeについては こちらで解説しています！👇 https://x.com/starriver0513/status/2032043227512259014

😇「Cowork？code？はにゃ？」という方は是非↑ 今回は、海外で実際にバズっているSNSマーケティングの自動化術を5つ紹介します。うち2つは僕も実際に今やっている設定で、残り3つは海外マーケターの間で急速に広まっている活用法です。スケジュールタスクに入れるための指示文もそのまま公開します。 ぶっちゃけよく分からなくても、コピペできれば使えます。 活用法①：毎朝の「SNSブリーフィング」による意思決定の自動化 どんな活用法か： 毎朝9時に、「今日SNSで何を投稿すべきか」を全部まとめた指示書を自動生成させる使い方です。海外のSNSマーケターを中心に急速に広まっています。 具体的には、今週のタスクリストを読み込んで「今日投稿すべきテーマ」「今週のSNS投稿の消化状況」「残りの投稿数と優先順位」を一覧にしてくれます。 普通にやると毎朝30分かけて「今日は何を投稿しよう」と考える必要があります。これを入れれば起きたら全部まとまっている。30分→0分です。 スケジュールタスクの指示文テンプレート例： 【タスク名】毎朝SNS投稿プラン 【頻度】毎日（平日のみ） 【実行時間】9:00

以下のファイルを読み込んで、今日のSNS投稿プランを作成してください。

【読み込むファイル】

  • 01_設定ファイル/weekly-tasks.md
  • 01_設定ファイル/about-me.md
  • 02_ナレッジ/X記事企画リスト.md（テーマのストックから選ぶ）

【出力フォーマット】 ⏰ 日付・曜日 📋 今週のSNS投稿 進捗（消化率%）

■ 今日投稿すべきテーマ（優先順位付きで最大3つ）

  1. 【テーマ名】 → ターゲット： → フックの方向性（短期的快楽/逆説/ネガティブ訴求）： → 参照ナレッジ：

■ 投稿ネタメモ → 昨日までの作業で思いついた新しいテーマ候補があれば追記

出力先：03_出力/SNS投稿プラン/YYYY-MM-DD_今日の投稿プラン.md 海外マーケターの間でポイントと言われているのは「フックの方向性」まで出させていることです。 テーマだけ出されても「で、どう書き始めるの？」と考える時間が発生します。フックの方向性まで出しておくと、そのまま執筆に入れます。考える時間をゼロにするのが目的です。 活用法②：1本のコンテンツを「5媒体に自動変換」 どんな活用法か： 例えば1本のX長文記事を書いたら、それをX短文ポスト・Instagram用キャプション・YouTube台本のネタ帳・メルマガ・LINE配信文に自動変換させる使い方です。 これは「コンテンツリパーパス」と呼ばれる手法で、海外のマーケターが今一番やっていることです。1本のコンテンツから5〜10個の派生コンテンツを作ります。手動でやると1本あたり2〜3時間。スケジュールタスクなら0分です。 おすすめは毎週金曜の夜に設定すること。「今週書いたX記事」を全部まとめて変換させて、土日の間にCoworkが処理して、月曜朝には来週分のコンテンツが揃っている状態を作れます。 スケジュールタスクの指示文テンプレート： 【タスク名】週次コンテンツリパーパス 【頻度】毎週金曜日 【実行時間】22:00

以下の手順で今週のX長文記事をマルチ媒体コンテンツに変換してください。

【Step 1】03_出力/X記事/ から今週作成した記事を全て読み込む

【Step 2】各記事を以下の5形式に変換する

① X短文ポスト（280文字以内×3パターン） → フックは短期的快楽/逆説/ネガティブ訴求の3種で作り分ける → 元記事の一次情報（数字・体験談）を必ず1つ入れる

② Instagram用キャプション（1投稿分） → 1行目にフック → 箇条書きで要点を5つ → CTAはプロフィールリンクへの誘導 → ハッシュタグ10個

③ YouTube台本ネタ帳（構成案のみ） → タイトル案3つ → 構成（導入→本編3セクション→まとめ→CTA）の骨子だけ → 「この記事のどの部分が動画で映えるか」をコメントで添える

④ メルマガ用要約（400字以内） → PREP法で圧縮 → CTAは記事本文への誘導

⑤ LINE配信文（200字以内） → 「星川です！」で始める → 1つの数字だけ抜き出してフックにする → CTAは1つに絞る

【品質チェック】 □ 各変換で元記事の一次情報が最低1つ入っているか □ brand-voice.mdの文体が守られているか □ 媒体ごとの文字数制限を守っているか

【出力先】03_出力/リパーパス/YYYY-MM-DD_元記事タイトル/ 1本の記事から5媒体×週3〜5本で、月間60〜100コンテンツが自動生成される計算です。 手動でこれをやったら月40時間。スケジュールタスクに入れたら月0時間になります。 活用法③：競合の投稿を「毎週自動分析」 何をやっているか： 毎週月曜の朝に、競合アカウント5つの直近1週間の投稿を分析したレポートを自動生成しています。 「あの人が最近何を発信しているか」「どんなテーマが伸びているか」「自分が取りこぼしているテーマはないか」

これを手動でチェックしていたら週2時間かかります。今は月曜の朝に開くだけです。 具体的にはClaude in Chrome（Coworkのブラウザ操作機能）を使って、指定したアカウントのプロフィールページを巡回させています。 スケジュールタスクに入れている指示文： 【タスク名】週次・競合SNS分析レポート 【頻度】毎週月曜日 【実行時間】8:00

  • 直近1週間で最もエンゲージメントが高かった投稿TOP3（内容の要約）

  • 自分（星川）がまだ発信していないテーマ

【出力フォーマット】 ■ 今週の競合動向サマリー（300字以内で全体像を把握できるように）

■ アカウント別分析（上記の項目を各アカウントごとに）

■ 自分が未発信のテーマ提案 → 「競合が伸ばしているが、自分がまだ書いていないテーマ」を3つ提案 → 各テーマについてフックの方向性も添える

■ 注意すべきトレンド → 業界全体で話題になっていること、今週中に投稿した方がいいもの

出力先：03_出力/競合分析/YYYY-MM-DD_週次競合分析.md 「自分が未発信のテーマ提案」セクションが一番価値があります。 競合の動向を見るだけなら誰でもできます。そこから「じゃあ自分は何を書くべきか」まで提案させています。 活用法④：投稿パフォーマンスの「自動振り返り」 何をやっているか： 毎週日曜の夜に、今週の自分の投稿のパフォーマンスを分析したレポートを自動生成しています。 どの投稿が伸びたか、どのフックが刺さったか、どの時間帯のエンゲージメントが高かったか これを毎週振り返ることで、翌週の投稿精度が上がります。 手動でやると面倒でサボります。スケジュールに入れておけばサボりようがないです。 スケジュールタスクに入れている指示文： 【タスク名】週次・投稿パフォーマンス分析 【頻度】毎週日曜日 【実行時間】21:00

今週の自分のSNS投稿パフォーマンスを分析してください。

【分析手順】 Step 1：03_出力/X記事/ から今週投稿した記事を全て読み込む Step 2：各投稿について以下を分析する

【分析項目】 各投稿について：

  • 使用したフック（短期的快楽/逆説/ネガティブ訴求）
  • 一次情報の有無と内容
  • テーマカテゴリ（AI活用/ビジネス/ツール/マインド）
  • 文字数
  • 投稿曜日・時間帯

【出力フォーマット】 ■ 今週の投稿サマリー → 投稿数、テーマ別の内訳

■ 今週のベスト投稿 TOP3 → なぜ伸びたと思われるかの仮説を添える

■ 今週のワースト投稿 1つ → なぜ伸びなかったかの仮説を添える

■ 来週への改善ポイント（3つ以内） → 「来週はこのフックをもっと使う」「このテーマは反応が薄いので一旦やめる」など → 具体的なアクションとして書く

■ フック別の成績 → 短期的快楽 / 逆説 / ネガティブ訴求、それぞれ何回使って、どれが一番反応が良かったか

出力先：03_出力/パフォーマンス分析/YYYY-MM-DD_週次分析.md 「フック別の成績」を出させているのがポイントです。 2ヶ月続けると、自分のアカウントで一番刺さるフックのパターンがデータで分かります。僕の場合は「逆説」が一番反応率が高かったです。これはデータを取らないと分かりません。 活用法⑤：投稿カレンダーの「毎週自動生成」 どんな活用法か： 毎週日曜の分析レポートを受けて、翌週の投稿カレンダーを自動で作らせる使い方です。海外では「Content Calendar Automation」と呼ばれていて、スケジュール機能の活用法として一番人気があります。 月曜の朝に「今週何を投稿するか」が全部決まっている状態を作れます。しかも先週の分析結果を踏まえて、伸びたテーマの続編や、反応が薄かったテーマの差し替えが反映されています。 スケジュールタスクの指示文テンプレート： 【タスク名】来週の投稿カレンダー生成 【頻度】毎週日曜日 【実行時間】22:00（※パフォーマンス分析の1時間後に設定）

以下の情報を全て読み込んで、来週（月〜金）のX投稿カレンダーを作成してください。

【読み込むファイル】

  • 03_出力/パフォーマンス分析/ の最新レポート（今週の振り返り）
  • 03_出力/競合分析/ の最新レポート（競合動向）
  • 02_ナレッジ/X記事企画リスト.md（テーマストック）
  • 01_設定ファイル/weekly-tasks.md（来週の予定）
  • 01_設定ファイル/brand-voice.md（文体ルール）

【カレンダー生成ルール】

  • 月〜金で毎日1投稿（長文記事）＋ 1〜2投稿（短文ポスト）
  • 先週伸びたテーマの続編を最低1本入れる
  • 先週反応が薄かったテーマは差し替える
  • 競合が伸ばしていて自分が未発信のテーマを最低1本入れる
  • セミナー告知など日付指定の投稿は該当日に固定する
  • テーマカテゴリが偏らないように（AI活用/ビジネス/ツール/マインドを満遍なく）

【出力フォーマット】

日付曜日長文記事テーマフックの方向性短文ポスト（1〜2本）メモ

■ カレンダーの意図説明（200字以内） → 「今週はこういう方針で組んだ」の説明

■ テーマストックの残数 → X記事企画リストから何本消化済み・残り何本か

出力先：03_出力/投稿カレンダー/YYYY-MM-DD_来週カレンダー.md ポイントは、活用法④のパフォーマンス分析→この投稿カレンダーの順番で、日曜の夜に2つ連続で走るように設定することです。 分析結果をそのまま翌週の計画に反映できます。これが回り始めると、毎週勝手にPDCAが回ります。やることは月曜朝にカレンダーを確認して「OK」と言うだけです。 この5つを組み合わせると何が起きるか 整理します。 月曜朝： 競合分析レポート＋来週の投稿カレンダーが完成済み 毎朝： 今日のSNSブリーフィング（投稿テーマ＋フック＋優先順位）が完成済み 毎日の作業： ブリーフィングを見て記事を書くだけ 金曜夜： 今週の記事がマルチ媒体に自動変換される 日曜夜： 今週の振り返り＋来週のカレンダーが自動生成される 人間がやるのは「記事を書く」だけになります。 企画・分析・計画・変換・振り返りなど、全部Claudeが自動で回してくれます。 僕は③の競合分析と④のパフォーマンス分析を実際にスケジュールタスクで回していますが、この2つだけでも「何を書くべきか」の意思決定が圧倒的に速くなりました。

5つ全部入れたら、SNSマーケティングの「考える仕事」の大半が自動化されます。残りの「自分にしか書けない一次情報を入れる」部分だけが人間の仕事です。 注意点：スケジュールタスクの制約 正直に書きますが、万能ではないです。 ①PCが起動していないと動きません。 スケジュールタスクはClaudeデスクトップアプリが開いている状態でのみ実行されます。PCがスリープ状態だとスキップされます。ただし、復帰後に自動で再実行してくれます。朝起きたらまずPCを開く習慣をつけるのがおすすめです。 ②品質チェックは人間がやります。 自動生成されたコンテンツをそのまま投稿するのは危険です。必ず自分の目で見て、一次情報が入っているか、自分の言葉になっているかを確認してから出してください。 スケジュールタスクの設定方法（30秒で終わる） Coworkのチャット欄に /schedule と打つ タスク名・説明・指示文・頻度を入力 「Schedule」を押す 以上です。これだけです。 既存のスケジュールタスクは、サイドバーの「Scheduled」から確認・編集・一時停止・削除ができます。 海外ではもう当たり前になっているこの仕組み、日本ではまだほとんどの人がやっていません。 今回ご紹介した競合分析とパフォーマンス分析は実際に僕が回している設定ですし、他の3つも指示文テンプレートをそのままコピペで使えます。ぜひ試してみてください。 こちらで今回の記事は以上です！お読みいただきありがとうございました！
