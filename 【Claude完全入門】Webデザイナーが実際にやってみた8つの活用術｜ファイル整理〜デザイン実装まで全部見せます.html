📌 ポイント

1. Claudeの本質 — 「相談相手」ではなく「実行する部下」

ChatGPTやGeminiは回答を返すだけで最後に手を動かすのは人間。Claudeのデスクトップ版はローカルファイルを開いて整理・名前変更・保存まで実行する自律型エージェント。Coworkタブが本体で、フォルダ・コネクタ（MCP）・スキルを組み合わせて動かす。必要なもの：Mac・Claudeプロプラン（月約3000円）・Google Chrome。

2. ファイル整理 — スクリーンショット21枚を内容読み取りで自動分類

日付だけの命名だったスクリーンショットをClaudeが中身を読み取り（テキスト・画像内容まで理解）、カテゴリ別にフォルダを作ってリネーム・移動。「YouTubeの参考動画」「オンラインセミナー」「スクール参考サイト」など意味のある名前で整理。一度やった作業はスキルとして保存できるので次回は「さっきのやり方で」と言えばOK。

3. Notion + Canva連携 — スタイルガイドを自動生成して保存

Claudeにリンクを貼るだけでNotionの中身を読み取り、スタイルガイドのテンプレートを適切な場所に1ページ作成。さらにCanvaとも連携して同じ内容をプレゼン形式のCanvaテンプレートとして生成。叩き台やアイデア出しレベルなら十分実用的で、コピペ→デザイン調整の工程が丸ごとなくなる。日本語対応も指示1つで変換してくれた。

4. タスク管理 — 「おはよう」→今日のスケジュールが自動生成

毎朝「おはよう」と声をかけるスキルを作成。Googleカレンダー+NotionタスクリストをAIが読み取り、「集中できる午前中にクリエイティブな作業・15分単位でタスク分割」という本人の仕事の癖を踏まえたタイムスケジュールを提案。アドバイスも付けてくれる。これをスキルにして習慣化するのが基本の使い方。

5. Claude Code — Figmaデザインから1ページ完全実装まで

LPの即席生成（アニメーション・写真入り）、FigJamでのユーザーフローマップ・サイトマップ自動生成が可能。さらに自分のFigmaデザインを読み取りHTML/CSS/JSでコーディング→WordPress化まで実行。以前はエンジニアに50〜100万かかっていた実装レベルが、コードを知らないデザイナーでも日本語の会話だけで実現できる。

6. AIを使いこなすために必要なのは「言語化能力」

雑務がゼロになったとき、Webデザイナーの価値は「何をなぜ作るか」という経営判断とディレクションに移行する。AIに何ができるかを把握し、何が課題でどこを人間がチェックするかを設計する力が単価に直結する。ChatGPT記憶のClaudeへの移植機能（メモリインポート）も紹介。
