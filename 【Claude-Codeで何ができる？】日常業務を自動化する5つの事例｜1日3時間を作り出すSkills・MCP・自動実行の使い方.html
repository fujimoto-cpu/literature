📌 ポイント

1. なぜ自動化が必要か — 「5分の雑務が23分を奪う」

研究によれば一度の集中が中断されると再び深く入るまでに平均23分かかる。5分の雑務が1日10回発生するだけで失われる集中時間は3時間以上。時短ではなく「集中の分断をなくす」ことが本当のゴール。雑務に脳のリソースを取られないことが自動化の本当の効果。

2. 4つの武器 — Skills / MCP / MDファイル / 自動実行

Skills：手順を登録して毎回同品質で動かす。MCP：Gmail・Googleカレンダー・GoogleドライブにClaude Codeから直接アクセス。MDファイル：過去の方針・文体ルール・マニュアルをMarkdownで持たせる。自動実行：HooksやcronでClaude Codeを定時起動。この4つを組み合わせると人間がやっていた業務をそのまま委任できる。

3. タスク整理の自動化 — 毎朝7時にタスクリストが完成

タスク抽出スキルが起動→昨日の議事録MDから宿題を抽出→昨日の日報から未完了を引き継ぎ→Google Calendar MCPで今日・明日の予定を取得→優先度順のタスクリストを保存。これを自動実行で朝7時に動かすと「朝起きたら1日の地図が手元にある」状態になる。

4. メール返信の自動化 — 30通が5分で完結

Gmail MCPで未読メール取得→過去のやり取りMDファイルを参照（相手の文体・温度感・ネクストアクション）→CLAUDE.mdの文体ルール（文末・箇条書き上限・件名文字数）に従って返信案を生成→Gmailの下書きに保存。1通あたり10秒、30通で5分。確認して送信ボタンを押すだけ。

5. ミーティング準備・スケジュール調整・プレゼン資料

ミーティング準備：朝出社時点で全ミーティングの準備資料（参加者・前回宿題・想定質問）が完成。スケジュール調整：「Aさんと30分」と1行依頼→候補日メールが下書き済み→返信が来たら「確定して」の1行→カレンダー登録+確認メールまで完了。合計30秒。プレゼン資料：過去議事録・企画書・市場調査のMDを読み込み→Google Drive MCPでGoogleスライドを直接生成。1行の依頼で数時間かかっていた企画書作成が完了する。

💡 ゆりこの活用メモ

① まずメール返信かタスク整理を1つだけ始める 全部一度に自動化しようとしない。頻度が最も高いメール返信か毎朝必ず発生するタスク準備のどちらか1つから。文体ルールをMDに書き出す作業が一番最初のステップ。明日の朝、自分の文体ルール（文末・件名文字数・箇条書き上限）を1ファイルに書き出してみる。

② CLAUDE.mdにゆりこのルールを言語化する 現状すでにCORINとのやり取りでルールが蓄積されている。CLAUDE.mdに「スケジュール調整の優先度：午前は集中時間を確保・バッファ1日1-2時間」を明文化すると、スケジュール調整の自動化がすぐ使える状態になる。
