🎯 クロードコードの「Remote Control」機能を使うと、スマホ・ブラウザ・軽量PCなど任意のデバイスから自宅PCのObsidian＋クロードコード環境にそのまま接続でき、場所を選ばない「ながら作業」が実現できる。コマンド1つで起動でき、カスタムスキル・MCPサーバー・CLAUDE.md設定がすべてそのまま動く。

📌 ポイント

1. Remote Control とは何か — 自宅PCをどこからでも操縦できる仕組み

claude --remote-control コマンドを打つだけで、自宅PCのクロードセッションに外部デバイスから接続できる状態が作れる。通信は暗号化済みで、認証情報は使い捨てで自動処理されるため、VPN設定などの専門知識は不要。接続後は自宅のカスタムスキル・MCPサーバー・CLAUDE.mdの設定がすべてそのまま動く。「本当に家のパソコンをスマホに取り込んだ」状態になる。

2. Dispatch・Channelsとの違い — Remote Controlが圧倒的に安定している理由

AnthropicはDispatch（モバイルアプリ）・Channels（Telegram/Discord経由）・Remote Controlの3つのリモート手段を提供している。Dispatchは起動に時間がかかったり、プロジェクト・文脈の引き継ぎが弱かったりと使いにくい。Channelsは事前にMCPプラグイン設定が必要でハードルが高い。Remote Controlは「進行中のセッションをそのまま別デバイスで継続できる」唯一の手段であり、セッション文脈・カスタムスキルが完全に引き継がれる。

3. セットアップ手順 — コマンド1つ＋設定1箇所で完了

①ターミナルで claude --remote-control を実行 → 接続先の選択（Obsidian運用なら「Same Directory」=1番を選ぶ）→ QRコードを読み取るかURLをブラウザで開く。②既存セッションをリモート化したい場合は、セッション内で /remote-control と入力するだけ。③毎回コマンドを打つのが面倒な場合は /config からリモートコントロールを「True（常時オン）」に設定する。接続直後は一度メッセージを送信するまでスラッシュコマンドが認識されないため、最初に何か一言送ること。

4. 使えるもの・使えないもの — claudianだけ注意

✅ 使えるもの：スラッシュコマンド、カスタムスキル、MCPサーバー、CLAUDE.md、ローカルファイルへのアクセス。❌ 使えないもの：claudianで立ち上げたチャット（claudianはCLIセッション外）。Remote ControlはCLIセッション起点なので、claudianユーザーはCLI側にメインの作業環境を移す必要がある。また、ノートPC使用時はスリープ状態・蓋を閉じた状態だとリモートが切れるため、画面ロック・ディスプレイオフのまま運用すること。

5. 1日の使い方イメージ — 場所を選ばない作業フロー

朝：ベッドでスマホから昨日のセッションに接続し、アイデアを固める。午前：デスクで集中作業。煮詰まったらカフェに軽量PCを持ち出してブラウザから継続。昼休み：会社PCのブラウザから自宅セッションを開いて作業（会社規定の確認は必要）。夕方・夜：電車でスマホアプリから音声入力でObsidianに記録、ソファで1日の振り返りをiPadで行う。PCの前に一度も戻らないまま1日が終わる、というワークフローが可能になる。

💡 ゆりこの活用メモ

① 朝のアイデア出しをベッドから始める 翌朝のために前夜に claude --remote-control を立ち上げておく。起床後すぐにスマホのClaudeアプリを開き、kemioや案件の続きをベッドから投げ込む。PCを開かなくても「思いついた瞬間」を逃さない。

② 移動時間をObsidian更新タイムに変える 電車・タクシーの中でスマホアプリから音声入力でLiteratureNoteやタスクの整理をクロードに依頼する。Obsidianのドキュメントがリアルタイムで更新されるので、帰宅後の「まとめ作業」が不要になる。

③ /config でリモートコントロールを常時オンに設定する 毎回コマンドを打つのが面倒なので、最初に /config → リモートコントロールを True に設定しておく。これで毎朝PCを立ち上げてターミナルで claude を起動するだけで外出先からすぐ繋がれる状態になる。
