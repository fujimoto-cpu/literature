📌 ポイント

1. 技術スタック — Claude Code × Expo × RevenueCat の最小構成

フロントはクロードコードに Expo（React Native ベース）で書かせ、Windowsからでも iOS 審査に出せる。バックエンドは作らず、ローカル保存（Expo SQLite）で完結させてプライバシー・実装コストを両方クリア。課金は RevenueCat、分析は PostHog（MCPサーバーで Claude Code と直結）、App Store 申請も App Store MCPサーバーに記入してもらう。「手書きコードは1行もない」レベルまで AI に寄せる。

2. 逆算思考 — 「作りたいもの」から「売れる数字」へ

従来は「作りたいアプリ→作る→出す」の順算思考だったのを反転。先に「月20万円」を決めると、脳が自動で「1日6,300円 = 1,000円買い切り6本 = CVR1%なら600DL/日」のように分解し始める。曖昧なゴールだと情報収集も曖昧になる。数字で決めると、Xバズ／ASO／継続利用設計のどれに張るかまで現実的に詰められる。

3. アイデア発掘 — トレンド × マイクロフラストレーション

SNSでバズる前提でアイデアを選ぶ。「今、何が流行ってる？」（AIサブスク・VOD・漫画）と「自分の中の小さなイライラ」（サブスク管理面倒）を掛け算する。ひらめきは散歩・風呂・寝起き・読書中などデフォルトモードネットワーク状態で来やすい。さらに「半歩先のセンス」が必要で、これは才能ではなく方法論（参考書『こうやってセンスは生まれる』）。

4. 需要検証 — 作る前に ChatGPT で偽スクショを出す

開発に入る前に、生成AI（ChatGPT image）でプレビュースクリーンショットだけ作ってXに投稿。今回は5万インプ獲得＝需要ありと判断してから着手。開発中も「カレンダー表示こんな感じ」とBuild in Publicで進捗ポスト。反応が薄ければピボット、強ければ確信を持って続行。「作ってからバズるか祈る」を完全に逆転させる。

5. MVPで4〜5日リリース — 完璧主義を捨てる

個人開発はスタートアップと同じで、市場に受け入れられるか不確定なまま数ヶ月作り込むのは時間の浪費。最低限のパフォーマンスとセキュリティをクリアしたら出す。「短期間で作った」をユーザーには強調しすぎないが、Claude Code でそこまでできるのは事実。マネーフォワード等の大企業にも脆弱性はあるので、完璧は目指さない。

6. 拡散される1ページを設計する — スクショ前提UI

Xでバズった投稿は「アプリのスクショ1枚で何のアプリかわかる」状態だった（100万インプ獲得）。代表ページを1枚デザインしておくと、X／TikTokどちらにも刺さる。バズ→ランキング上昇→ストア内オーガニック流入、という導線まで含めて設計する。

7. 課金は WebView 逃がしも検討余地あり

App Store内課金は30%（申請で15%）手数料。一方Web経由のStripe決済なら3.6%だが、Web課金させる正当な理由がないと審査で弾かれる。初手は素直に RevenueCat、後で売上が積み上がってからWeb決済の導線を作るのが現実的。

8. ロングゲーム視点 — 単発バズじゃない普遍原則

「Claude Codeで完全自動化」「1ヶ月で成果」みたいな話はほぼ嘘。今回成果が出たのは継続発信・勉強・登録者10万・書籍出版・クロードコードアカデミー運営という蓄積があったから。継続・楽しむ・挑戦し続ける、という普遍原則を信じてロングゲームで考える（参考書『ロングゲーム』）。

💡 ゆりこの活用メモ

① 明日の朝、AICO/MEADOWの「月◯円」を数字で決めて壁に貼る 思考法_最終目的逆算思考の実践版。「いつかブランド成功させたい」じゃなくて「2026年内にMEADOW月15万」みたいに数字化する。動画の通り脳が勝手に分解し始めるから、CD志望のキャリアも「Award何件／月／年」みたいに逆算で書き出してCEOノートに置く。

② デザイン提出の前に「スクショ1枚で伝わる代表ページ」を必ず1枚作る癖をつける kemio・Armillary・小山案件すべて、SNS拡散される前提で「これ1枚で何の企画かわかる」ビジュアルを最初に決める。動画と同じで、これを最初に作ると残りのデザインがブレない。デザインに時間がかかりすぎる課題への直接の解。

③ AI推進で「作る前にスクショだけ出す需要検証ポスト」を社内提案に転用する 社内向けAIツール提案も同じ。Figma/ChatGPTでモック1枚作って#社員room投稿→反応見てから本実装、というMVPフローを定着させる。引地さん含む18名に対する展開でも「先に偽スクショ→反応で判断」が刺さる。
