📌 ポイント

1. YouTube競合分析ツール — マーケットインでコンテンツを生む

50チャンネルの動画を登録者数対再生数比率でスコアリングし、「バズっているのにチャンネルパワーが低い」動画を自動ピックアップ。GoogleトレンドAPIと組み合わせて「上昇検索ワード × 競合少なめ」の勝ちパターンを抽出する。さらに自分のセミナー・YouTube音声をベクトルデータベース（RAG）に蓄積することで、市場ニーズと自分の生データをかけ合わせたコンテンツを自動生成する。Claude Code がこのツールをMCPやCLI経由で直接操作できるため、ツールを開く手間すらなくなる。

2. スライド生成 + カスタムプレゼンタービュー — セミナーDXを完全自動化

nanoba APIを叩いてスライドを自動生成し、台本→スライド変換スキルも実装。さらに独自のプレゼンタービュー（カンペ表示）をWebアプリとして構築し、スマホのQRリンクからスライド送り・レーザーポインターとして使える仕組みも自作している。サーバー上で0.5秒間隔で同期するため、リアル登壇でも100人規模の勉強会でワイヤレスコントロールが可能。

3. 講座コンテンツ自動化 — Zoom終了から学習サイト公開まで全自動

Zoomクラウドレコーディングがダウンロード可能になったタイミングをトリガーに、文字起こし・要約・テスト問題・チャプター作成・動画格納を自動実行。手動で行うと半日かかる作業が、承認なしで完全自動化される。学習サイト自体もClaude CodeとMCP接続し、「このあたりで詰まってます」と話しかけると全勉強会の文字起こし（RAGに格納済み）から最適な動画をレコメンドする。

4. カスタムタスク管理ツール + LINE連携 — カレンダー同期でタスクを消化可能にする

AsanaやTrelloを使わず自社ツールをゼロから構築。リスト・タイムライン・スケジュールビューを持ち、タスク発生時にGoogleカレンダーと自動同期する。LINEをハブとしてタスク追加・カレンダー登録・通知が全て行える。API公開済みでClaude Codeからタスクを操作でき、ウィークリーMTGのアジェンダを「完了・未完了タスク抽出→カレンダー登録」まで自動生成する。

5. 商談→見積もり→開発の自動化パイプライン — エージェントが要件定義から開発着手まで

商談音声をアップロードするとヒアリングアシスタントが話者分離し、自動でヒアリング項目を埋めていく。承認後、見積もりサービスが要件定義書を生成し、「承認済み」ステータスに変更した瞬間に Claude Code が開発を0→5フェーズまで自律的に進行する。営業代理店でも対応可能な仕組みで、「システムを作るためのシステム」を構築することで月100件規模のさばき方を設計している。

6. 動画編集 + オートウェビナー — リモーション連携でコンテンツ資産を最大活用

Claude Code × Remotionで動画編集を自動化。過去のセミナー動画をオートウェビナー化し、Zoomのチャット履歴をリアルタイム再現する仕組みも構築。タイマー連動でプレゼント配布も自動化しており、1度作ったコンテンツが繰り返し収益を生む仕組みになっている。

💡 ゆりこの活用メモ

① 「痛みから自動化」の思考を即実践する 次に「めんどくさい」と感じた業務をメモし、翌朝 Claude Code に「これ自動化できる？」と壁打ちするところから始める。エンジニア知識ゼロでも Claude Code 自身が設計してくれる。

② タスク管理 × カレンダー連動を最優先で取り入れる タスクとカレンダーが分離しているのはゆりこの課題と完全一致。「タスクをカレンダーに自動同期する仕組み」を Claude Code に依頼するのが最短アクション。明日の朝、/company で壁打ちしてみる。
