どうも、すぐるです！ Claude Cdoe、使い始めて8ヶ月ほど？で作業環境をかなり最適化しました。

最初はMacBookの画面1枚でやってたんですけど、今はモニター2台追加、トラックボール、骨伝導マイク、MacBookスタンド、ARグラスまで入れてます。ソフト側もtmuxで5並列セッション、音声入力、hooksで自動通知。

「環境に投資した方がいい」とは聞くけど、具体的に何を買えばいいのかわからないって人が多いと思うので、自分が実際に使ってるものを全部書きます。ぶっちゃけ「買って後悔したもの」も含めて正直に。

ハードウェア編

1. MacBook Pro M4 Max / 128GB RAM

これが母艦です。Claude Codeはクラウドで動くのでスペックは関係ないと思われがちですけど、128GBのRAMは効きます。

ブラウザ30タブ、VS Code、tmuxで5セッション、Ollama（ローカルLLM）、Playwright（ブラウザ自動化）。これを全部同時に動かすと64GBだとスワップが発生する。128GBだと余裕です。

M4 Maxにしたのはバッテリー持ちとGPU性能のバランス。Ollama でQwenをローカルで動かすときにGPUが効く。

ぶっちゃけ: 正直、Claude Codeだけなら64GBで足ります。128GBが必要になるのはOllamaでローカルLLMを動かしつつ、PlaywrightでブラウザをAPIで操作しつつ、tmuxで5セッション回す、みたいな「全部同時」のとき。そこまでやらないなら64GBのM4 Proで十分です。128GBは「あると安心」であって「ないと困る」ではない。

MacBookの画面だけでClaude Codeを使うのは正直キツい。

自分の構成:

  • 左モニター: Claude Codeのターミナル（tmuxで分割）
  • 右モニター: ブラウザ、ドキュメント、参照資料
  • MacBook画面: Slack、Discord、メール等のコミュニケーション

BenQ GW3290QT（31.5インチ WQHD）を検討中です。USB-C 65W給電でケーブル1本で済むのと、デイジーチェーンで2台目に繋げるのがいい。

ぶっちゃけ: モニターは1台追加するだけでも全然違います。2台がベストだけど、まず1台から始めるなら27インチ4KかWQHD。安いやつでいい。ケーブル1本で給電もできるUSB-C対応のやつにしておくと、デスク周りがスッキリする。4Kの方がテキストがきれいだけど、Claude CodeはターミナルなのでWQHDでも全然問題ない。

3. ロジクール MX ERGO S（トラックボール）

これはマジでおすすめです。

普通のマウスだと1日10時間以上PC使ってると手首がやられる。トラックボールに変えてから手首の痛みがゼロになりました。

MX ERGO Sは角度が20度傾けられるので、自然な手の位置で操作できる。静音なのでミーティング中に操作しても音が入らない。

Claude Codeはキーボード中心なのでマウスの出番は少ないんですけど、ブラウザ操作やSlackのときに使います。

ぶっちゃけ: 最初の1週間は使いにくいです。普通のマウスと操作感が全然違うので。でも1週間で慣れて、2週間後には普通のマウスに戻れなくなります。MX ERGO Sは￥17,800で安くはないけど、手首の故障で病院通いになるよりは安い。あとAmazon限定で壁紙ダウンロードが付いてくるけど、正直いらない。

4. Shokz OpenComm2（骨伝導マイク）

これがClaude Codeの音声入力用です。

Claude CodeはTypelessというアプリと組み合わせると、タイピングせずに指示を出せます。「このファイルを読んで、バグを探して」みたいな指示を声で出す。

なぜ骨伝導かというと:

  • 耳を塞がないので環境音が聞こえる
  • ノイズキャンセリングマイクでクリアに音声入力できる
  • 16時間バッテリーなので1日持つ
  • 軽いので長時間つけてても疲れない

普通のイヤホンだと耳が蒸れるし、ヘッドセットは重い。骨伝導が一番バランスいいです。

ぶっちゃけ: 音声入力は場所を選ぶのが最大の弱点。カフェや共有オフィスでは使えない。自宅作業メインの人向けです。あと音声認識の精度が完璧じゃないので、コードの変数名とかはタイピングの方が確実。音声入力が一番活きるのは「この記事のトーンをもう少しカジュアルにして」「ファクトチェックして」みたいな日本語の自然言語指示です。

あともう1つ正直に言うと、OpenComm2は音楽を聴くには向いてない。骨伝導なので音質はそこそこ。音楽用にはAirPodsを別で持ってます。

5. ONED Majextand（MacBookスタンド）

MacBookの画面を目線の高さまで上げるスタンド。

これ、MacBookの裏に貼り付けるタイプで、使わないときは完全にフラットになる。持ち運びの邪魔にならない。

目線が下がると首が痛くなるんですよね。スタンドで画面を上げるだけで、長時間作業の疲労が全然違います。外部キーボードと組み合わせて使ってます。

ぶっちゃけ: これは安いし軽いし、全員買った方がいい。￥6,000くらいで首の痛みがなくなるなら最高のコスパ。ただしMacBookを上げるなら外部キーボードが必須になります。Apple純正のMagic Keyboardか、何か好きなやつを用意してください。

6. XREAL One Pro（ARグラス）

これは正直おすすめしないです。笑

428インチ相当の画面が目の前に出る。スペック上はすごい。3DoF対応で頭の動きに追従する。

ただ解像度がFHDなので、コードを長時間読むにはキツい。目も疲れる。結局モニターの前に座ってる時間が長いので、出番がほとんどない。 ちなみに、まじで一回使って使うのやめました。悲しい。。。

ぶっちゃけ: 約6万円で、正直あんまり使ってないですw 買ったときはテンション上がったんですけど、結局モニターの前に座ってる時間が長いので出番がない。新幹線で使おうとしたけど、隣の人の目が気になって断念したこともある。「面白いガジェット買ったな」くらいの気持ちで、実用性を期待して買うものではないです。自宅メインの人は確実にいらない。

7. Oura Ring 第4世代

これはClaude Codeとは直接関係ないんですけど、作業環境の一部として入れてます。

睡眠の質、心拍数、コンディションを毎朝Claude Codeに投げて健康レポートを生成してます。「今日のコンディションスコアが低いから軽めのタスクにしよう」みたいな判断に使ってる。

Claude Codeのスキルとして /health-check を作ってて、Oura APIからデータ取得→分析→レポート生成まで自動です。

ぶっちゃけ: 約5万円のリングなので、Claude Code環境としては優先度低い。ただ自分はこれで睡眠スコアが可視化されてから、深夜作業を減らすようになった。睡眠が悪いと翌日の判断力が落ちて、Claude Codeへの指示も雑になる。結果的にAI出力の品質に影響する。間接的だけど効果はあります。

8. Anker Power Bank Fusion

モバイルバッテリー兼USB充電器。10000mAh、30W出力、ケーブル内蔵、コンセント直差し。1台3役。　

カフェやコワーキングで電源がないときにMacBookを延命させる用。Claude Codeの5並列セッションはバッテリーを食うので、外出時はこれ必須です。

ぶっちゃけ: MacBook Pro M4 Maxだと30Wじゃ充電しながら使うのは厳しい（消費の方が大きい）。でも「バッテリーの減りを遅くする」くらいの効果はある。コンセントが空いてたら直差しで充電器としても使えるので、持ち歩くのは1台で済む。

ソフトウェア編

9. tmux — 5並列セッション

これがClaude Codeの生産性を一番上げてくれたソフトです。

tmuxでターミナルを5分割して、それぞれ別のClaude Codeセッションを走らせる。

  • セッション1: メイン作業（記事執筆、コーディング）
  • セッション2: リサーチ（Grok検索、Web調査）
  • セッション3: ビルド・テスト
  • セッション4: バックグラウンドタスク（画像生成、動画処理）
  • セッション5: 予備（急ぎのタスク用）

1つのセッションがリサーチで待ってる間に、別のセッションで記事を書く。並列で動かすことで待ち時間がゼロになります。

ぶっちゃけ: tmuxは最初のハードルが高い。キーバインドを覚えるのに1-2日かかる。でもそれを超えたら戻れない。自分の場合、tmux導入前は1日に完了できるタスクが3-4個だったのが、今は8-10個になってます。

あとtmux使わなくても、VS Codeのターミナル分割やiTerm2のタブでも似たことはできます。ただtmuxの方がSSH越しでも使えるし、セッションが切れても復帰できるので安定感がある。 （ちなみに、一周回って最近はVScodeの拡張機能で回すことが増えてきました）

10. 音声入力（Typeless + Shokz）

Claude Codeへの指示を音声で出すスタイル

長い指示を書くとき、タイピングだと1分かかるものが音声なら15秒で終わる。特に「この記事のトーンをもう少しカジュアルにして」「ファクトチェックして」みたいな抽象的な指示は声の方が速い。

Typelessはリアルタイム音声入力アプリで、話した内容がそのままテキストとしてClaude Codeに入力される。精度が高くて、日本語もかなりいける。

ぶっちゃけ: 音声入力の一番の問題は「恥ずかしさ」です。最初はPCに向かって声を出すのが恥ずかしかった。でも1週間で慣れます。自宅なら誰も見てないし。

あとmacOS標準の音声入力でも結構使えます。Typelessの方が精度は高いけど、まず試すならmacOS標準（Fn2回押し）で十分。

11. hooks — 完了通知

tmuxで5セッション回してると、どのセッションが完了したかわからない。

hooksのStop イベントでmacOS通知を飛ばすようにしてます。Claudeが応答を完了したら「タスク完了」って通知が来る。これがないと5セッション管理は無理です。

設定は簡単で、settings.jsonに数行書くだけ。通知音も変えられるので、タスクの種類ごとに音を変えてます。ファイル編集はTink、ビルド完了はHero、テスト完了はGlass。音で「あ、ビルド終わった」ってわかる。

ぶっちゃけ: 最初は通知が多すぎてうるさかった。5セッション全部から通知が来るので。今はメインセッションだけ音あり、残りはバナー通知のみにしてます。

12. Claude Code Max $200プラン

月$200。高いと思うかもしれないですけど、自分の場合は月に記200本以上、コーディング、リサーチ、自動化をClaude Codeでやってるので、人件費換算だと圧倒的に安い。

100プランとの違いは並列セッション数と思考予算の余裕。5並列で回すなら200は必要です。$100だと3並列くらいが限界。

ぶっちゃけ: 200プランの最大の価値は「制限を気にしなくていい安心感」です。100プランだと「今月あとどれくらい使えるっけ」って気になる瞬間がある。$200だとその心配がほぼない。思考予算もhighで常時回せる。

ただ正直、Claude Codeを始めたばかりの人は100プランで十分。並列セッションの必要性を感じてから200に上げればいい。最初から$200にする必要はないです。

買わなくてよかったもの・やめたもの

ここまで「買ってよかったもの」を書いてきたけど、逆に「いらなかった」ものも正直に書いておきます。

高級デスク・チェア

作業環境の記事だと「10万円のチェアを買え」って話になりがちですけど、自分はIKEAの1万円のやつを使ってます。正直、チェアよりモニターとスタンドの方が先です。笑

4Kモニター

WQHDで十分。4Kの方がきれいだけど、Claude Codeのターミナルでその差を感じるかと言われると微妙。4Kにするくらいなら、同じ予算でWQHDを2台買った方がいい。
