📝 要約

🎯 Notion・Motion等のタスク管理ツールを手放し、Claude CodeとMarkdownテキストファイルだけで「3ヶ月継続できるタスク管理システム」を構築した実践記録。朝・昼・夜の声かけだけで全自動化される。

🗺️ 全体像

flowchart TD
    A[☀️ 朝：今日のタスク作って] -->|月次・週次・前日を読込| B[📋 デイリーファイル自動生成]
    B --> C[🏃 日中：進捗どう]
    C -->|Claude Memと照合| D[✅ 完了・未完了・未記載タスク検出]
    D --> E[🌙 夜：振り返りやって]
    E -->|AIがまとめ＋アドバイス| F[📝 デイリーファイルに記録]
    F -->|金曜| G[📅 週次→月次 自動同期]
    G --> A

📌 ポイント

1. Notionをやめた3つの理由

①タスク管理自体がタスクになる（運用コストが本末転倒）②データが人質になる（サ終・値上げリスク）③別ツールを開く手間（Claude Codeと環境を統一したかった）。 テキストファイルに移行することで「ツール依存ゼロ・10年後も読める・AIとの相性抜群」という3つを一気に解決した。

2. 5階層マークダウン構造

Yearly → Quarterly → Monthly → Weekly → Daily の5ファイルで管理。年間目標から日次タスクまで繋がることで「何のためにやるか」を見失わない。 週次ファイルが作れなかった週も月次＋日次で補完してくれるため、完璧にやらなくても崩れない。3ヶ月で59日分の実績データが蓄積。

3. 3つのスキルで全自動化

ToDo（朝タスク生成）・ToDo2（進捗確認）・/EOD（夜の振り返り）の3スキルを作成。 特にToDo2はClaude Mem（AI記憶）とタスクを突き合わせて、ToDoに書き忘れた作業まで自動検出する。/EODでは振り返りを声で話すとAIがまとめ＋アドバイスを生成してデイリーファイルに記録する。

4. 弱点と正直な評価

Claude Memの検索精度は完璧ではなく拾い漏れがある。スキルの初期調整に時間がかかる（一度完成すれば毎日使えるので投資として十分）。 向いている人：タスク管理を挫折してきた人、AIコーディングエディター使用者。向かない人：抜け漏れを絶対許せない人、100%カチッとした管理をしたい人。

💡 ゆりこの活用メモ

① 明日の朝、CORINに「今日のタスク作って」と声で頼んでみる タスク管理が苦手・1日に複数タスクをこなすのが難しいゆりこにとって、会話でタスクを自動生成する仕組みは「管理の手間ゼロ」を実現できる。まず月次・日次の2ファイルだけで試すのが現実的なスタート。

② /EODをCORINに実装する 夜帰宅後に「振り返りやって」と話すだけで日記＋タスク照合が自動化される。今の/nikkiスキルに「タスク照合」機能を追加するか、別スキルとして独立させるか検討の価値あり。
