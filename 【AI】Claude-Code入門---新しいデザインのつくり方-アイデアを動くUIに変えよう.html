📝 要約

🎯 UIデザインコミュニティ「BONO」のカイクンが、非エンジニア・デザイナー向けに claude-code のインストールから動くToDoアプリの生成まで、ステップバイステップで解説するチュートリアル動画。

🗺️ 全体像

flowchart TD
    A[Cursorまたはターミナルを開く] --> B[インストールコマンドを実行]
    B --> C[Claudeアカウントでログイン]
    C --> D[claude コマンドで起動確認]
    D --> E[仕様書MDファイルを作成]
    E --> F[ドラッグ&ドロップで指示を渡す]
    F --> G[ToDoアプリが自動生成される]
    G --> H[スクリーンショットで修正指示]

📌 ポイント

1. インストールは4ステップ — ターミナルにコマンドを貼るだけ

Cursor（またはTerminal.app）を開き、AnthropicのQuickStartページのコマンドをコピペ→エンター。成功すると「Claude Code Successfully Installed」と表示される。その後 claude コマンドを打ってログインし、推奨設定でセットアップ完了。有料プラン（月$17・約3000円）が必要。「登録したら即解約予約して1ヶ月だけ試す」方法が紹介されている。

2. 曖昧な指示より仕様書を渡す — MDファイルをドラッグ&ドロップ

「ToDoアプリ作って」とだけ言うと確定要素が多すぎて意図しないものができる。ユーザー像・課題・体験のゴール・必要な機能・UIの方向性をMDファイルに書いてドラッグ&ドロップで渡すと精度が上がる。長文を直接チャット欄に貼るとバグが起きやすいため、ファイル経由が推奨。

3. 修正はスクショ貼りで直感的に — 言葉で説明しにくい部分も対応

「この部分の色を変えたい」など指示しづらい時は、画面をスクショ（Command+Shift+4）してコマンドVで貼り付け→「ここの色を黒に」と指示できる。ただし画像付き指示はトークン消費が多いため使い所を選ぶこと。

4. 基本操作6種 — 覚えておくと格段に使いやすくなる

①プロンプト送信（エンターで即送信・改行はOption+Enter）②停止（Escキー）③ファイル指定（@マークまたはドラッグ&ドロップ）④編集承認（Yes/このセッション中はYes/No）⑤モードの切り替え（Shift+Tab：Accept Edits On / Plan Mode / Auto）⑥スラッシュコマンド（/status /clear /skills等）

5. Plan Modeを活用 — 実行前に計画を確認できる

Shift+Tabで「Plan Mode On」に切り替えると、実行するかわりに詳細な計画を先に提示してくれる。「これで合ってる？」を確認してから実装に進める。カイクン曰く「めちゃくちゃ使う」機能。

💡 ゆりこの活用メモ

① 今日の夜にインストールを完了させる Cursor既に入れてるなら残りはコマンド貼るだけ。QuickStartページを開いて、ターミナルにコマンド1行コピペ→claudeアカウントでログインの2ステップだけ。明日の朝には使える状態にしておく。
