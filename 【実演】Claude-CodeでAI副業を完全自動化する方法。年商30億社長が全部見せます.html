📝 要約

🎯 Claude Codeを使ってアプリ作成→LP作成→デプロイまでを約30分で完成させ、AI副業の「商品・販売・集客」3ステップを完全実演した動画。

📌 ポイント

1. Claude Codeの稼ぎ方は4パターン

①アプリ/サービスを作って売る ②ノート作成+SNS集客で販売 ③Claude Codeの使い方を教える ④自分の仕事を効率化する（実質的な稼ぎ）。三上氏は全部やっており、AI導入支援では1ヶ月で大きな売上を立てた実績あり。Claude Codeが使えるだけで「月50万払うから教えて」というニーズも現実に存在する。

2. ビジネス収益化の絶対の順番

商品 → 販売動線 → 集客 の順が鉄則。集客から考えるのは間違い。アプリ（商品）が存在してはじめてLP（販売）が作れ、SNS/広告（集客）が意味を持つ。Claude Codeはこの3ステップ全部を自動化できる。

3. Adnes（タスク管理MCP）でClaude Codeを"覚醒"させる

Claude CodeにAdnesコネクタを連携すると、ゴール・タスクを記憶しながら迷わず実行できるようになる。コンテキストウィンドウ（100万トークン）を超えても忘れないため、長期プロジェクトで力を発揮する。まず「プロジェクトフォルダ作成 → Adnesでタスク設定 → ゴール確認」が最初のセットアップ。

4. Claude Codeへの指示は「目的から逆算」が命

「アプリ作って」だけでは不十分。「今これを作ってリリースする、販売動線も作る、集客まで持っていきたい」というゴールと現状を言語化して渡すことでClaude Codeが正しいタスク分解をしてくれる。三上氏の言葉：「理想と現状の差分を感じるセンサーが人間の価値」。

5. デプロイ・LP・集客まで全部Claude Codeが自動実行

Vercel CLIのインストール→デプロイ、LP作成→Codex MCPで画像生成→実装まで、人間は「どうする？」に答えるだけ。集客タスクもAdnesが「YouTube紹介→X告知→NOTE記事執筆→有料課金実装」の順で自動提案してくれる。

💡 ゆりこの活用メモ

① 明日の朝、Claude Codeに「副業/新サービスの商品・販売・集客の3ステップを整理して」と投げてみる まずAdnes（または類似のタスク管理MCP）でゴールを設定するだけでClaude Codeの動きが変わる。今のAI導入推進業務にも使える発想。

② 社内AI推進でクライアント向けに「30分でアプリを作る実演」を見せる この動画と同じフローをゆりこが再現して社内デモに使うと説得力が上がる。難しいコードは不要、目的から整理する部分を練習しておく。

③ 「集客は一瞬で終わらない」を意識してタスクを小さく分解する アプリ作成は30分でも、集客は継続作業。Claude Codeに集客タスクを全部出力させてから1つずつ着手する習慣を作る。
