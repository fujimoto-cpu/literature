📌 ポイント

1. HERMES Agent — XAIを使えるAIエージェントCLI

HERMES Agent は Claude Code や Codex 系のCLIエージェント。最大の特徴は「XAIのGrokをサブスク経由で接続できる」こと。これまでX上の情報取得は従量課金API or ブラウザ操作（時間とトークンの無駄）の二択だったが、月額固定で公式に大量取得できるようになった。

2. セットアップ手順 — 3ステップで完了

①CLIで curl ... | sh でHERMESインストール ②hermes auth xai を叩いて承認画面で許可（タイミング次第でエラー出るが手順は正しいので待つ） ③hermes tools でConfigを開き XSearchをスペースキーでON（ここが解説記事で抜けがちな落とし穴）。動画生成・画像生成・動画解析もここで一緒にONにできる。

3. Grok 4.3 への切替が必須

HERMES起動後に /model で xai/grok-4.3 を選ばないとXSearchが発火しない。デフォルトモデルのまま使うと「なぜか検索されない」状態になる。

4. Claude Code スキル化で真価を発揮

HERMES単体でも使えるが、Claude Code から skill-creator で「HERMES経由でX情報を取得→Excel出力するスキル」を作成すれば、自然言語で「◯◯の最新投稿3つまとめて」と書くだけでバックグラウンドでHERMES起動→Grok検索→整形までフルオート。動画生成スキルも同じノリで作れる。

5. 料金構造の妙 — Xサブスクで完結

Anthropic定額（Claude Code） × X定額（Premium+でGrok/XSearch）= API従量課金ゼロでX情報を大量に動かせる。情報収集をXに依存している人にとっては月6,000円が一気にペイする構造。
