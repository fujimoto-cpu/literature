📌 ポイント

1. フロントエンドデザインスキル（最多DL）

AI感のないおしゃれなWebサイトを自然言語一行で生成できる公式スキル。DL数が圧倒的に多く、スキルを入れたあと「このデザインルールを踏襲しつつ自社カラーで作り直して」と依頼すれば自社オリジナルのスキルも作れる。

2. Playwright（ほぼ必須）

ブラウザ操作を自然言語で行えるプラグイン。ログインが必要な環境にアクセスしてコンテンツを自動投稿するなど、APIが公開されていないサービスへの連携に必須。Claude Code本来の外部ツール連携力を引き出す鍵。

3. スキルクリエイター（スキルを作るスキル）

欲しいスキルを自然言語で伝えるだけでClaude Codeが自動生成・動作検証・修正までループしてくれる公式スキル。「YouTube動画URLを渡したらQ&A形式のExcelを作るスキル」を1回の指示で完成させるデモを実演。

4. Claude.mdマネジメント

ルールが肥大化しがちなClaude.mdを定期監査・整理・最適化してくれる。古いルールの削除や自動改善もできるため、Claude.mdを長期運用するなら必須。

5. Discordプラグイン（リモート操作）

事務所のPCにDiscordBot経由でClaude Codeを遠隔操作できる。スマホから音声入力でスライド作成・ニュース投稿を指示し、帰宅中に完了させることが可能。PDF形式でDiscordに返信させれば確認も外出先でできる。
