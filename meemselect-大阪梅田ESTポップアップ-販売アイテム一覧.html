📝 要約

🎯 @meemselect が大阪・梅田ESTで開催したポップアップストアの全67型アイテム一覧。Y2K×グランジ×フェミニンを融合させた独自世界観のウィメンズブランド。

👗 トップス・ボディスーツ系

  • カットアウト・コルセット・レースアップなど「締める・見せる」ディテールが多数
  • ボディスーツ、オフショルダー、キャミソール、ロングスリーブと幅広いシルエット
  • カラーはピンク・グレー・白・黒の4色展開が基本
  • “DON’T BE JEALOUS.” “Please Shine Yours” などセンチメンタルなグランジテキストプリントが特徴的

👖 ボトムス・デニム系

  • フレアデニム、カーゴパンツ、プリーツスカートなどY2Kシルエットが豊富
  • カットアウト加工・レースアップ・ガータービジューなどのデコラティブ加工が多い
  • デニムはヴィンテージウォッシュ加工が主流

👜 バッグ・アクセサリー系

  • キルティング×チェーンバッグが複数展開（Y2Kクラシック）
  • チュールフリル・フリンジ・ハートキルティングなどガーリー路線も充実
  • ネイルチップ、キャップ、ニットビーニーなどの小物も展開

💡 Creative Direction Note

  • 「グランジ×フェミニン」の共存が明確なブランドアイデンティティ。ピンク×黒×白の3色を軸にモノクロベースにピンクを差し色として使うカラーパレット設計が参考になる
  • セットアップをSETUP / SET UPと表記し、「構成として見せる」商品企画が多い。ファッションに限らずコンテンツの「一式感」を演出するヒントになる
  • ポップアップのアイテムリストをカルーセル投稿にする構成はECっぽくなりすぎず、ルックブックっぽい空気感を保てている点が巧い
