📝 要約

🎯 Claude Codeで5人のAI営業チームを構成し、問い合わせ受信から提案書作成・フォローメールまでを完全自動化する方法を解説。人間は商談のみに集中できる。

🗺️ 全体像

flowchart TD
    A[問い合わせメール受信] --> B[リサーチ君\n企業情報抽出・課題推定]
    B --> C[台本君\n商談スクリプト・想定Q&A作成]
    C --> D[👤 人間が商談実施]
    D --> E[議事録君\n文字起こし→議事録作成]
    E --> F[提案書君\n15〜20枚スライド自動生成]
    F --> G[フォロー君\nフォローアップメール作成]
    H[オーケストレーター\n親エージェント] --> B
    H --> C
    H --> E
    H --> F
    H --> G

📌 ポイント

1. オーケストレーター構成 — 1人の親エージェントが5人に指示

「要件定義」フォルダに各AIメンバーの役割定義を格納する。0番ファイルがオーケストレーター（指揮官）で、ここを起動するだけで5人が並列実行される。5並列で動くため、単独実行の5分の1の時間で全工程が完了する。人間のマネジメントコストもゼロ。

2. リサーチ君 → 台本君 — 商談前準備を全自動化

問い合わせメールの内容だけを入力すると、リサーチ君が企業名・事業モデル・課題を自動抽出・構造化する。その出力を受けて台本君がアイスブレイク〜課題深掘り〜提案のアジェンダと想定Q&Aを生成する。スクリプトテンプレートを要件定義に入れておけば自社スタイルに合わせた台本が出力される。

3. 議事録君 → 提案書君 — 商談後作業を完全ゼロ化

商談の文字起こし（Google Meet・Zoom等の自動出力を特定フォルダに格納）を議事録君が読み取り、整形された議事録を生成。その内容を提案書君が受け取り、15〜20枚の提案スライドをノー編集で一発出力する。カラーはコーポレートカラー指定可。クオリティは「社内俗人化防止」に十分なレベル。

4. フォロー君 — 商談後のメール自動作成

文字起こしデータをもとに、御礼の挨拶・議論ポイントの振り返り・次のアクション提案まで含むフォローアップメール文章を自動生成する。商談実施後にテンプレートを起動するだけで完成。

5. 横展開の可能性 — 営業支援ツールとしての提案

この営業チームの仕組み自体が「俗人化防止・コスト削減」の好例となり、クライアントへのAI研修提案のデモとして使える。同様の構造をバックオフィス・採用・CS等に展開可能。

💡 ゆりこの活用メモ

① 社内営業フローへの応用 コネクトの案件提案・クライアントフォローに同じ構成を適用できる。まず「CLAUDE.md方式の要件定義フォルダ」を作り、リサーチ・台本・提案書の3エージェントから試す。

② Armillary.等のクライアント提案に活用 商談前に企業リサーチ〜アジェンダを自動生成する仕組みを入れるだけで、打ち合わせの質が上がる。文字起こしはGoogle Meetの自動書き起こしで代替可能。
