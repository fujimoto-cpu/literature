📌 ポイント

1. Cloudflareは「全部乗せ」のクラウドサービス

ウェブサイト・ウェブアプリの配信、セキュリティ、DNS（ドメイン管理）、データベース（D1）、ファイル保存（R2）、簡易メモ保存（KV）がこれ1つで完結する。世界のウェブサイトの4分の1がCloudflare経由で表示されているほど普及している。転送量（ユーザーへの配信）は無料、保存容量や処理回数が増えると一部サブスク課金が発生する仕組み。

2. 覚えるべき5つの用語：Worker / R2 / D1 / KV / Wrangler

Worker＝サイトを配信する拠点（世界中に分散、ユーザーに一番近い拠点から配信するので表示が速い）。R2＝画像や動画などファイルの保存場所。D1＝Excelのようなデータベース。KV＝秘密鍵や短い設定値を保存する簡易メモ。Wrangler＝これら全部をコマンドで操作するCLIツール。このWranglerをクロードコードに使わせることで、クロードコード経由でCloudflareを丸ごと操作できるようになる。

3. MCP接続はボタン1つ＋コピペだけ

Cloudflareの管理画面で「Onboard your agent」をクリックするとセットアップ用プロンプトがコピーされる。それをそのままクロードコードに貼り付けて送信するだけでMCP接続が完了する（途中でCloudflareへのOAuthログイン認証が挟まる）。接続後は設定画面の「コネクタ」欄にCloudflareが接続済みと表示される。

4. Wranglerも入れておくとより細かく操作できる

Cloudflare公式ドキュメントのインストール手順（URL）をそのままクロードコードに渡せば、コマンドインストールまで代行してくれる。これでD1・R2・KVの細かい設定もクロードコード経由で可能になる。

5. MCP＋Wranglerを「スキル」としてまとめるのが一番のおすすめ

都度指示せず、スラッシュコマンド一発でCloudflare操作を呼び出せるようにエージェントスキル化しておくと運用が楽になる。動画内では実際に「テスト用のLPを作って、画像はR2に保存、D1でデータベースも使った仕組みを入れて公開して」と自然言語で指示するだけで、サイト作成→画像保存→データベース作成→デプロイまで一気通貫で完走できていた。

💡 ゆりこの活用メモ

① 自分専用の業務効率化ツール置き場にする ちょっとした社内向けWebツール（チェックリスト・簡易フォーム・ダッシュボード等）を作るたびにCloudflareへ無料デプロイしておけば、URL一つで社内共有できる状態を量産できる。自作ツールを気軽に公開する今の動き方と相性がいい。

② 会社サイト・ポートフォリオの本番運用先としても検討できる 独自ドメインを取得してCloudflareに登録すれば、コーポレートサイトやポートフォリオサイトの編集をクロードコード上で完結できる。CDの実績を公開するポートフォリオサイトを将来本番運用する際の選択肢の一つとしてメモしておく。
