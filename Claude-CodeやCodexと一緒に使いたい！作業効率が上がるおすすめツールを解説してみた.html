📌 ポイント

1. VS Code拡張機能 — ファイルを見ながらAIを横で使う

Claude CodeやCodexの拡張機能をVS Codeに入れると、ファイルの中身を見ながら横でAIに指示できる。おすすめはOffice Viewer（Excel/Word/PowerPoint/PDF/Markdownを綺麗に表示）・Material Icon Theme（拡張子ごとにアイコン表示）・Japanese Language Pack。ファイルを選択した状態でAIに「ここを直して」と言うと、選択部分だけを認識して修正してくれる。デスクトップアプリ（Claude Desktop/ChatGPTデスクトップ）よりファイルが見やすいので、ファイルを見ながらAIを使うならVS Code＋拡張機能としてのAI利用がおすすめという結論。

2. Obsidian Callouts — AIの出力を読みやすく変換する

Obsidianは高性能メモ帳アプリ。グラフビューは見栄えは良いが実用性はそこまでないという評価で、本当に便利なのは「Callouts」という記法。無機質な文章をAIにCalloutsで整形させると、注意書きなどが色分けされて非常に読みやすくなる。ObsidianのCEOがGitHubで公開している「Obsidian-Markdown」スキルをClaude Codeに入れれば、この変換を自動でやってくれる。HTMLで整形するより使用トークンが少ないのもポイント。Web Clipper拡張機能を使えば、Chromeで見ている記事をそのままObsidianに取り込める。

3. 音声認識アプリ — タイピングの5〜10倍速く指示できる

AquaVoice・Typeless・SuperWhisperなど音声認識アプリを使うと、長いプロンプトも喋るだけでAIに渡せる。有料ツールに抵抗があれば、Mac/Windows標準の音声入力機能やChatGPTデスクトップアプリの文字起こし機能（他のアプリを使っている時でも裏で動く）で代替できる。本格運用するならHyperX SoloCastのような外部マイクを使うと精度が上がる。

4. Raycast — Snippets・ウィンドウ管理・Focus機能

Raycastは「あらゆる操作にショートカットを与える」無料ツール（Mac中心、Windowsはベータ版）。①Snippets：よく使うプロンプト（例：翻訳指示）をキーワードで登録して呼び出せる。クリップボードの内容を変数として埋め込むことも可能。②Window Management：ウィンドウを左右半分・中央などに一瞬で移動でき、複数のClaude Code/ターミナルを並列で動かす時に便利。③Focus：AIの処理待ちの間にX/YouTubeを見て放置してしまう対策として、指定サイトを時間制限でブロックできる。

💡 ゆりこの活用メモ

① VS Code＋Office Viewer/Material Icon Themeを試す 案件フォルダのExcel/PowerPoint/PDFをVS Code上でまとめて確認できるようにすると、ファイルを開き直す手間が減る。次に資料確認するタイミングで拡張機能だけ入れてみる。

② 音声入力でCORINへの指示を試す Mac標準の音声入力（設定→キーボード→音声入力）だけでも試せる。長いプロンプトを打つ場面（タスク分割の指示など）で一度使ってみると効果が分かりやすい。
