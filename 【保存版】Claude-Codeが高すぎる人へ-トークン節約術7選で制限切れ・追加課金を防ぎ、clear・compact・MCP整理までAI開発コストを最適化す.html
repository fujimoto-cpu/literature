📌 ポイント

1. /clear と /compact の使い分け — 「消す」か「圧縮」か

タスクが切り替わったら迷わず /clear で会話履歴を全消去する。同じタスクを継続したまま軽くしたいなら /compact で会話を要約圧縮。/compact が基本のベースで、/clear は「完全に別の話題」に切り替える時専用。自動圧縮の閾値をJSONで70%に下げておくと毎回手動で打つ手間が省ける（中級者向け）。

2. CLAUDE.md の最適化 — 毎回読まれるファイルを絞る

CLAUDE.md はすべてのリクエストで毎回先頭から読み込まれる固定コスト。1万トークンを超えているケースもあるが、目安は50〜200行。専用ワークフローはスキル（Skill）として切り出しておくと、呼び出した時だけ読まれる設計になりトークンを節約できる。フォルダ階層ごとにCLAUDE.mdを分けて置くと「そのフォルダ内だけ」で読まれる運用も有効。

3. モデルの使い分け — Sonnet が基本・Opus は最終手段

デフォルトは Sonnet（速い・安い）で十分。Opus 4.8 は「コンビニに専用車で行くようなもの」という比喩通り、明らかにオーバースペックなケースが多い。UltraCode（最大1000体並列エージェント）は費用対効果を計算してから使う。デスクトップアプリなら画面上のセレクターでモデルを直感的に切り替え可能。

4. スコープ指定と Plan モード — 広範囲スキャンを防ぐ

「このファイルの30〜90行目だけ直して」のように対象をピンポイントで指定すると、不要なファイル全スキャンを回避できる。いきなり実行させず Plan モードで設計を先に立てるのもトークン節約の一手。デスクトップアプリのボタンから簡単に Plan モードに切り替えられる。

5. MCP の整理 — 不要ツールをカットする

MCP ツール定義もリクエストごとに固定コストとして毎回送信される。使っていない MCP は積極的に削除・無効化する。「不要な MCP があるか」を claude-code 自身に聞くと的確に整理提案してくれる（「自分のことは自分が一番知っている」ため）。

6. 自動チャージ OFF と月間上限設定 — 予算暴走を防ぐ

自動チャージをオンにすると同時セッションが多い日は1日で予算が溶ける。まず自動チャージを OFF に。どうしても制限を止めたくない場合は「月間上限だけ設定する」という折衷案がある。デスクトップアプリの「使用量」タブから設定可能。

7. 定点観測と Claude への相談 — 無駄を可視化して改善

/usage-stats コマンドでモデル別の消費内訳を確認。デスクトップアプリなら細かいセッションログをGUI確認できる。分からなければ Claude Code に「最近の挙動を見て無駄なトークン使ってる箇所を教えて」と直接聞くのが最速。自分の使い方のクセを AI に診断させる逆転の発想。

💡 ゆりこの活用メモ

① 明日の朝から /compact を習慣化する Claude Code を開いてタスクを継続する前に、まず /compact を打ってから作業開始する。同じ案件を数日続けて触るセッションでは特に効果が高い。「作業始める前に /compact」をルーティンに組み込む。

② CLAUDE.md と SKILL.md の見直しを週1でやる 今のCORIN環境はルールファイルが多い。毎週月曜に CLAUDE.md のトークン量を /context で確認して、スキルに切り出せる長文ルールを1つずつ移行していく。目安は「本体 200行以内」。

③ 自動チャージ OFF を今すぐ確認する Claude.ai の「使用量」タブで自動チャージの状態を確認。オンになっていたら即 OFF に。月間上限の設定もしておくと安心。
