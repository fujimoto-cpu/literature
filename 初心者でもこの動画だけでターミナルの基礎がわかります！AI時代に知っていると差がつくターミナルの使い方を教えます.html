📌 ポイント

1. AI時代だからこそターミナルを学ぶ理由

Claude CodeなどのAIコーディングエージェントは、ターミナル（CLI）をベースに動作する。デスクトップアプリはCLIの機能9割をカバーするが、CLIが大元。「なんとなく動いてるけど不安」という感覚を消すために、ターミナルの理解は必須。AIがエラーを出しても、スクショしてAIに聞けば解決できるため、今はむしろ学びやすい時代。

2. CLIの3つのメリット

①軽量・安定：グラフィックを描画しないため、デスクトップアプリより圧倒的に軽い。②大元の機能：Claude Codeはデスクトップ版より先にCLI版が更新される。CLIが源泉なので機能が最も揃っている。③キーボード完結：フォルダ操作をマウスなしで高速に行える。慣れればGUIより速い。

3. 重要な用語整理

ディレクトリ = フォルダのこと（開発用語）。カレントディレクトリ = 今いる場所。パス = ファイルの住所。絶対パス（ルートから全部書く）と相対パス（今いる場所からの相対位置）の2種類がある。コマンド = PCへの命令。コマンド名 スペース 対象 の形式が基本。打ち間違えると No such file or directory のエラーが返る。

4. 7つの基本コマンド

  • clear — 画面をきれいにする
  • pwd — 今いるディレクトリを表示（Print Working Directory）
  • ls — カレントディレクトリの中身を一覧表示（List）
  • cd [フォルダ名] — ディレクトリを移動（Change Directory）。cd .. で1つ上に戻る。タブ補完で候補が出る
  • mkdir [名前] — ディレクトリ（フォルダ）を作成（Make Directory）
  • rm -r [名前] — ディレクトリを削除。ファイルのみなら rm、強制削除は rm -rf
  • touch [ファイル名] — ファイルを新規作成

💡 ゆりこの活用メモ

① Claude Codeはデスクトップよりターミナルで起動を試みる デスクトップ版は重くて止まりやすい。ターミナルから claude コマンドで起動すると軽量で安定する。明日の朝、ターミナルを開いて claude と打ってみる。

② エラーが出ても読む習慣をつける No such file or directory など、エラー文は英語でも意味が取れる。読まずにスクショするより先に、まず1秒だけ読む。それでも分からなければAIに貼る。
