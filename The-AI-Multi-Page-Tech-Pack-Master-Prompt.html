📝 要約

🎯 ファッションのテクニカルパック（仕様書）をAIで自動生成するマスタープロンプト集。スケッチや2Dフラット図をアップするだけで、工場入稿レベルの7ページ構成の技術仕様書をChatGPTに一括生成させる。

📋 概要

@morchenliu が公開したワークフロー。手動で作成すると何時間もかかるテクニカルパックを、ChatGPT（GPT-4o / 画像認識モデル）にガーメントのフラット図とマスタープロンプトを投げるだけで一括生成する方法。出力はPDFに書き出してCanvaで仕上げる想定。

生成される7ページの構成

P1: カバーページ — ブランド情報・スタイル番号・季節・サイズ・リビジョン履歴・フロント＆バック図 P2: 構造詳細・コールアウト — 縫い仕様（SPI・糸種・縫い代）・補強点・エッジ仕上げ P3: BOM（資材リスト） — 生地・副資材・ジッパー・ボタン・スレッド・パッケージングまで全部品を表形式で列挙 P4: カラーウェイ＆アートワーク配置 — Pantone番号・アートワーク配置寸法・加工方法（刺繍・スクリーンプリント等） P5: サイズスペック — POM図（測定点ダイアグラム）＋全測定箇所の寸法・許容差・計測方法 P6: サイズグレーディング — ベースサイズから全サイズへのグレードルール一覧 P7: ラベル＆パッケージ — メインラベル・ケアラベル・ハンタグ・折りたたみ指示・ポリ袋仕様

⚠️ 注意事項

AI生成テクニカルパックは「構造化された初稿」として使う。工場送付前に測定値・素材仮定・縫製詳細・パッケージ仕様を必ず人間が確認・修正すること。不確かな部分はプロンプトの段階で「proposed」ラベルを付けるよう指示されており、TBC（要確認）はRed表示で区別される。

概要

制作者: @morchenliu ゴール: テックパック（仕様書）の手動作成を完全にスキップする。ChatGPTの画像認識機能でスケッチやレンダリングを解析し、工場入稿レベルのマルチページ技術資料を自動生成する。

🧠 Step 1: インプット

最低限必要なもの：ガーメントの明確な2Dスケッチ、フラット図、または3Dレンダリング。フロント＆バックの両面があるとベスト。

追加で精度を上げるもの（任意）：

  • 寸法詳細・パッケージングメモ・構造の意図
  • トリム・生地情報
  • ブランドアセット（ロゴ・ブランドカラー・タイポグラフィ例）

情報が構造化されているほど、生成されるテックパックの精度が高くなる。ファイルはデスクトップに保存しておくこと。

⚙️ Step 2: エンジン（使い方）

  1. ChatGPTを開き、ビジョン機能付きの最新モデルを使用していることを確認する
  2. ガーメントの画像（＋ブランドアセットがあれば）をチャットバーにドラッグ＆ドロップする
  3. 下記のマスタープロンプトをコピー＆ペーストする

📋 マスタープロンプト（コピペ用・必要に応じて編集）

アップロードしたテクニカルフラット図を使用して、ガーメント製造向けの完全で信頼性の高いマルチページ ファッション テクニカルパックを生成してください。出力は、ファッションムードボードやカタログページ、装飾的なインフォグラフィックではなく、プロのスタジオ・工場入稿レベルのテックパックとして仕上げてください。

アップロードしたテクニカルフラット図を唯一の情報源として使用してください。不必要なガーメント要素を創作しないでください。構造的な詳細が見えない場合は、業界標準の縫製構造に基づいて論理的に推測し、「proposed（推定）」と明記してください。すべてのページを通じて一貫性を保ってください（スタイル名・スタイル番号・シーズン・ベースサイズ・ガーメントのプロポーション・構造詳細・トリム・カラーウェイ・寸法・ラベル）。

クリーンな白黒テクニカルドローイングスタイルで、構造化されたテーブル・正確なコールアウト・明確なページタイトルを使用してテックパックを作成してください。全体を通じてプロのファッション製造用語を使用してください。すべてのスケッチは、正確なフロント・バックビュー・詳細拡大図・ステッチライン・シームラベル・地の目ロジック・必要に応じた寸法ガイドを備えたクリーンなベクタースタイルのテクニカルフラットにしてください。

📄 P1 — カバーページ / スタイルサマリー

メーカーがガーメントをすぐに把握できるエグゼクティブサマリーのカバーページを作成してください。

含める項目：

  • ブランド名：[ブランド名を入力]
  • ロゴプレースホルダー：[ロゴまたはロゴ配置を入力]
  • ブランド連絡先：[メール / ウェブサイト / 連絡先を入力]
  • スタイル名：[スタイル名を入力]
  • スタイル番号：[スタイル番号を入力]
  • ターゲットシーズン：[シーズンを入力（例：Fall/Winter 2026）]
  • ジェンダー / カテゴリー：[カテゴリーを入力]
  • ベースサンプルサイズ：[ベースサイズを入力（例：メンズ Mサイズ）]
  • 作成日：[日付を入力]
  • デザイナー名：[デザイナー名を入力]
  • リビジョン履歴テーブル（列：リビジョン番号・日付・変更内容・承認者）
  • ガーメントのフロント・バックのクリーンな白黒テクニカルフラット
  • シルエット・フィット・主要構造特徴・想定生地タイプを要約したガーメント説明文

📄 P2 — 構造詳細・コールアウト

テクニカルフラットをベースに、すべての可視・必要な構造箇所に番号付きコールアウトと詳細拡大図を追加した構造ページを作成してください。

含める項目：

  • 番号付き構造コールアウトを添えたフロント・バックのテクニカルフラット
  • 複雑な箇所の拡大スケッチ（カラー・ネックライン・フード・ポケット・カフス・ヘム・プラケット・クロージャー・ウエストバンド・ベンツ・シームなど、アップロードしたガーメントに応じて）
  • シームタイプ仕様（例：5本糸オーバーロック・フラットフェルドシーム・フレンチシーム・ツインニードルカバーステッチ・ロックステッチ・バインディング・バータック・エッジステッチ）
  • ステッチ指示（SPI・ステッチタイプ・糸種・糸の太さ）
  • 固定参照点からの正確な寸法を添えたハードウェア配置
  • ヘム・ネックライン・アームホール・カフス・ポケット開口部・ウエストバンド・生端のエッジ仕上げ指示
  • 補強ポイント（バータック・リベット・トップステッチ・ステイステッチ・芯地）
  • 縫い代基準の明記：[縫い代を入力（例：特に指定がない限り縫い代1cm）]

📄 P3 — BOM（資材リスト / Bill of Materials）

ガーメント1着の製造に必要なすべての物理的コンポーネントを列挙した詳細なBOMテーブルを作成してください。

BOMテーブルの列： アイテム番号 / コンポーネントカテゴリー / コンポーネント説明 / 配置・用途 / 繊維組成 / 生地重量またはトリムサイズ / カラー / サプライヤー・サプライヤーコード / 1着あたりの使用量 / 備考

含めるセクション：

  • 表地 / メイン生地：繊維組成・GSM・織り・ニットの種類・仕上げ・サプライヤー情報
  • 副資材生地：裏地・ポケット地・コントラスト生地・リブ・バインディング・メッシュ・芯地・インターフェイシング（該当するもの）
  • トリム・ハードウェア：ジッパー・ボタン・スナップ・リベット・鳩目・トグル・ドローコード・ゴム・ラベル・テープ・コードエンド・パッチ
  • スレッド：組成・糸番手・カラーマッチング指示
  • 芯地 / インターフェイシング：重量・配置・サプライヤー
  • パッケージングコンポーネント（該当する場合）
  • 全資材の1着あたりの使用量見積もり

※アップロードしたガーメントに不要なコンポーネントは含めない。不確かな場合は「標準構造に基づく推定（proposed based on standard construction）」と赤字で記載すること。

📄 P4 — カラーウェイ & アートワーク配置

カラーウェイとアートワーク配置のページを作成してください。

含める項目：

  • カラーウェイ表（列：カラーウェイ名・表地Pantone/TCXコード・副生地カラー・リブ/トリムカラー・スレッドカラー・ハードウェアカラー・アートワークカラー）
  • [カラーウェイ数を入力] 種類以上のカラーウェイオプション（1色のみ必要な場合を除く）
  • アートワークファイル参照テーブル（列：アートワーク名・ファイル名・ファイル形式・配置・スケール・加工方法）
  • 寸法矢印で正確なアートワーク配置を示したテクニカルフラット
  • 固定点からの正確なアートワーク配置寸法：
    • センターチェスト：フロントネックラインから計測
    • スリーブグラフィック：スリーブヘムから計測
    • バックグラフィック：CBネックシームから計測
    • ポケットロゴ：ポケット端から計測
  • 加工技法（例：刺繍・スクリーンプリント・パフプリント・熱転写・ウーブンパッチ・ラバーバッジ・ダイレクトtoガーメントプリント）
  • アートワークサイズ（cm またはインチ）
  • アートワークカラー仕様
  • 見当合わせ / 位置合わせ備考

※アップロードしたガーメントにアートワークが見えない場合は「アートワーク不要」のクリーンなレイアウトを作成し、適切な場合のみブランディング配置オプションを含めること。

📄 P5 — 寸法仕様 / ベースサイズ スペックシート

ベースサンプルサイズの詳細な寸法仕様ページを作成してください。

含める項目：

  • 明確な番号 / 文字の測定線を持つPOM図（Point of Measure ダイアグラム）
  • 必要に応じたフロント・バックの寸法図
  • POMテーブル（列：POMコード / 測定箇所名 / 測定説明 / ベースサイズ寸法 / 許容差 / 測定方法 / 備考）

ガーメントタイプに応じて含めるPOM（例）： 着丈 / バスト幅 / ウエスト幅 / ヘム幅 / ショルダー幅 / スリーブ丈 / バック幅 / アームホール / バイセップ幅 / カフス開口部 / ネック幅 / ネックドロップ / フード高さ・幅（該当する場合）/ カラー高さ（該当する場合）/ ポケット配置（該当する場合）/ 股下・股上・太もも・膝・裾開き（パンツの場合）/ スカート丈・ウエスト・ヒップ・裾周り（スカート・ワンピースの場合）

ベースサイズ [ベースサイズを入力] に対して業界標準の現実的な寸法を使用すること。寸法はアップロードしたテクニカルフラットと想定フィットと内部整合性を保つこと。

📄 P6 — サイズグレーディング

承認済みのベースサイズが全サイズ展開にどのようにスケールするかを示すサイズグレーディングページを作成してください。

含める項目：

  • サイズ展開：[サイズ展開を入力（例：XS・S・M・L・XL）]
  • ベースサイズを明確にマーク
  • グレーディングテーブル（列：POMコード / POM名 / XS / S / M（ベース） / L / XL / サイズ間グレードルール / 許容差）
  • ガーメントカテゴリーとフィットに基づいた現実的なグレードインクリメントを使用
  • バスト・ウエスト・ヘム・ショルダー・スリーブ・カフス・着丈の比例ロジックを維持
  • グレーディングがスタンダード・ゆったりフィット・オーバーサイズ・フィット・ユニセックス・メンズ・ウィメンズ・子供服のいずれかを備考に記載

📄 P7 — ラベル & パッケージング

ガーメントのブランディング・ラベル付け・折りたたみ・梱包方法を示すラベル＆パッケージングページを作成してください。

含める項目：

  • メインブランドラベルのデザインプレースホルダー
  • メインラベルの寸法
  • 正確なラベル配置（例：インナーバックネック・ウエストバンド・サイドシーム・インナーフェイシング）
  • 法的テキストプレースホルダー付きのケア / 組成表示ラベル
  • ケアシンボルプレースホルダー
  • BOMと一致する繊維組成テキスト
  • 原産国プレースホルダー
  • ラベル配置図
  • サイズラベルの配置
  • ハンタグデザインプレースホルダー
  • ハンタグサイズ
  • ハンタグの取り付け方法と正確な位置
  • 明確なステップ・バイ・ステップの図または番号付きテキストによる折りたたみ指示
  • ポリ袋仕様：寸法 / 素材 / 厚さ / 窒息警告の配置 / バーコードシールの配置 / サイズ・カラーシールの配置
  • 該当する場合はカートン梱包備考

📋 全体出力要件

  • 完全な7ページのテクニカルパックとしてフォーマットすること
  • 明確なページタイトルと一貫したページ番号付けを使用すること
  • 白背景に白黒ベクタースタイルのガーメント図を使用すること
  • テーブルは構造化され、読みやすく、工場向けであること
  • プロのファッション技術用語を使用すること
  • すべてのテクニカルフラットをアップロードした図と一致させること
  • ファッションポーズ・モデル・装飾的背景・ムードボード画像・ライフスタイル写真・不要なグラフィック装飾を追加しないこと
  • ビジュアルスタイリングより製造上の明確さを優先すること
  • 推測した情報には必ず「proposed（推定）」ラベルを付けること
  • 不明な情報はプロフェッショナルなプレースホルダーとして赤字で表示すること（例：[TBC supplier]・[TBC Pantone]・[TBC artwork file]）
  • 特に指定がない限りメートル法を使用すること
  • テックパック全体を通じて、ガーメントの寸法・構造詳細・素材・カラーウェイ・ラベル・パッケージング指示が内部整合性を保つこと

🎯 Step 3: エクスポート＆ブラッシュアップ

ChatGPTが完璧に構造化された生データを生成する。寸法を見直し、好みに合わせて生地組成を微調整し、PDFに書き出してCanvaで仕上げる。

⚠️ 重要な免責事項

AI生成テクニカルパックは常に完全な正確性を保証するわけではない。出力は「構造化された初稿」として使用し、工場やメーカーに送付する前に内容を必ず人間が確認・編集・修正すること。

  • 寸法・生地の仮定・トリム・構造詳細・パッケージング指示を再確認すること
  • 必要に応じてガーメント画像を再アップロードし、テックパックがデザイン意図に一致するまでChatGPTに特定のセクションを修正させること

A Workflow by @morchenliu

Goal: Completely bypass the manual creation of tech packs. Use ChatGPT’s advanced image recognition to analyze a sketch or render and generate a multi-page, factory-ready technical document.

🧠 Step 1: The Input

You need at least a clear 2D sketch, flat drawing, or 3D render of your garment. Front and back views work best.

You can also improve the output by feeding the AI extra supporting assets, for example measurement details, packaging notes, construction intentions, trims, or fabric information. Upload branding Assets if you do, E.g,: Logos, brand colours, typography example.

The more structured information you provide, the stronger and more accurate the generated tech pack will be. Save this to your desktop.

⚙️ Step 2: The Engine

  1. Open ChatGPT and ensure you are using the latest model with vision capabilities.
  2. Drag and drop your garment image into the chat bar. (And branding assets if you have)
  3. Copy and paste the Master Prompt below.

📋 THE MASTER PROMPT (Copy & Paste / Edit if Necessary)

Use uploaded technical flat drawing, generate a complete, believable, multi-page fashion technical pack for garment manufacturing. The output should look like a professional studio/factory-ready tech pack, not a fashion moodboard, catalogue page, or decorative infographic.

Use the uploaded technical flat drawing as the primary source of truth. Do not invent unnecessary garment features. If any construction detail is not visible, infer it logically based on industry-standard garment construction and clearly label it as “proposed”. Maintain consistency across all pages: same style name, style number, season, base size, garment proportions, construction details, trims, colorways, measurements, and labels.

Create the tech pack in a clean black-and-white technical drawing style with structured tables, precise callouts, and clear page titles. Use professional fashion manufacturing terminology throughout. All sketches should be clean vector-style technical flats with accurate front/back views, detail enlargements, stitch lines, seam labels, grain logic, and measurement guides where required.

Generate the following pages:

PAGE 1 — COVER PAGE / STYLE SUMMARY

Create an executive summary cover page that gives the manufacturer an immediate understanding of the garment.

Include:

  • Brand name: [INSERT BRAND NAME]
  • Logo placeholder: [INSERT LOGO OR LOGO PLACEMENT]
  • Brand contact details: [INSERT EMAIL / WEBSITE / CONTACT]
  • Style name: [INSERT STYLE NAME]
  • Style number: [INSERT STYLE NUMBER]
  • Target season: [INSERT SEASON, e.g. Fall/Winter 2026]
  • Gender/category: [INSERT CATEGORY]
  • Base sample size: [INSERT BASE SIZE, e.g. Men’s Medium]
  • Date created: [INSERT DATE]
  • Designer name: [INSERT DESIGNER NAME]
  • Revision history table with columns: Revision number, date, description of change, approved by
  • Clean black-and-white technical flats of the garment front and back
  • Brief garment description summarising silhouette, fit, key construction features, and intended fabric type

PAGE 2 — CONSTRUCTION & DETAIL CALLOUTS

Create a construction page using the technical flats as the base. Add numbered callouts and enlarged detail views for all visible or necessary construction areas.

Include:

  • Front and back technical flats with numbered construction callouts
  • Enlarged detail sketches of complex areas such as collar, neckline, hood, pockets, cuffs, hem, placket, closures, waistband, vents, or seams, depending on the uploaded garment
  • Seam type specifications, for example: 5-thread overlock, flat-felled seam, French seam, twin-needle coverstitch, lockstitch, binding, bartack, edge stitch
  • Stitching instructions including SPI, stitch type, thread type, and thread thickness
  • Hardware placement with exact measurements from fixed reference points where relevant
  • Edge finishing instructions for hem, neckline, armhole, cuff, pocket opening, waistband, or raw edges
  • Reinforcement points such as bartacks, rivets, topstitching, stay stitching, or fusing
  • Clearly state seam allowance standard: [INSERT SEAM ALLOWANCE, e.g. 1 cm seam allowance unless otherwise stated]

PAGE 3 — BILL OF MATERIALS / BOM

Create a detailed Bill of Materials table listing every physical component required to produce one garment.

Include a structured BOM table with columns: Item number / Component category / Component description / Placement & usage / Fiber content & composition / Fabric weight or trim size / Color / Supplier & supplier code / Consumption per garment / Notes

Include sections for:

  • Main fabric / self fabric: fiber content, GSM, weave or knit type, finish, supplier information
  • Secondary fabrics: lining, pocketing, contrast fabric, rib, binding, mesh, fusing, or interfacing where relevant
  • Trims and hardware: zippers, buttons, snaps, rivets, eyelets, toggles, drawcords, elastic, labels, tapes, cord ends, patches
  • Thread: composition, ticket size/weight, color-matching instructions
  • Fusing/interfacing: weight, placement, supplier
  • Packaging components if relevant
  • Consumption estimate per garment for every material

Do not include components that are not required by the uploaded garment. If unsure, mark the component as “proposed based on standard construction” in Red.

PAGE 4 — COLORWAYS & ARTWORK PLACEMENT

Create a colorway and artwork placement page.

Include:

  • Colorway chart with columns: Colorway name, main fabric Pantone/TCX code, secondary fabric color, rib/trim color, thread color, hardware color, artwork color
  • At least [INSERT NUMBER] colorway options, unless only one colorway is required
  • Artwork file reference table with columns: Artwork name, file name, file format, placement, scale, application method
  • Technical flat showing exact artwork placement using measurement arrows
  • Exact artwork placement measurements from fixed points (center chest from front neckline / sleeve graphic from sleeve hem / back graphic from CB neck seam / pocket logo from pocket edge)
  • Application technique (embroidery, screen print, puff print, heat transfer, woven patch, rubber badge, direct-to-garment print)
  • Artwork size in cm or inches
  • Artwork color specification
  • Registration/alignment notes

If the uploaded garment has no visible artwork, create a clean “No artwork required” layout and include optional branding placement only if appropriate.

PAGE 5 — MEASUREMENT SPECIFICATIONS / BASE SIZE SPEC SHEET

Create a detailed measurement specification page for the base sample size.

Include:

  • POM diagram showing the garment with clear numbered or lettered measurement lines
  • Front and back measurement diagrams where needed
  • POM table with columns: POM code / Point of Measure name / Measurement description / Base size measurement / Tolerance / How to measure / Notes
  • Include relevant POMs only for the garment type: Body length / Chest width / Waist width / Hem width / Shoulder width / Sleeve length / Across back / Armhole / Bicep width / Cuff opening / Neck width / Neck drop / Hood height & width if relevant / Collar height if relevant / Pocket placement if relevant / Inseam, rise, thigh, knee, leg opening if trousers / Skirt length, waist, hip, hem sweep if skirt or dress

Use realistic industry measurements for base size [INSERT BASE SIZE]. Measurements should be internally consistent with the uploaded technical flat and intended fit.

PAGE 6 — SIZE GRADING

Create a size grading page showing how the approved base size scales across the full size range.

Include:

  • Size range: [INSERT SIZE RANGE, e.g. XS, S, M, L, XL]
  • Base size clearly marked
  • Grading table with columns: POM code / POM name / XS / S / M (Base) / L / XL / Grade rule between sizes / Tolerance
  • Use realistic grading increments based on garment category and fit
  • Maintain proportional logic between chest, waist, hem, shoulder, sleeve, cuff, and body length
  • Add notes explaining whether grading is standard, relaxed fit, oversized fit, fitted, unisex, menswear, womenswear, or childrenswear

PAGE 7 — LABELS & PACKAGING

Create a labels and packaging page showing how the garment should be branded, labelled, folded, and packed.

Include:

  • Main brand label design placeholder + dimensions
  • Exact label placement (inside back neck / waistband / side seam / inner facing)
  • Care/content label with legal text placeholder + care symbols placeholder
  • Fiber content text matching the BOM
  • Country of origin placeholder
  • Label placement diagram + size label placement
  • Hangtag design placeholder, size, attachment method and exact position
  • Folding instructions using clear step-by-step diagrams or numbered text
  • Polybag specification: dimensions / material / thickness / suffocation warning placement / barcode sticker placement / size & color sticker placement
  • Carton packing notes if relevant

GENERAL OUTPUT REQUIREMENTS

  • Format as a complete 7-page technical pack.
  • Use clean page titles and consistent page numbering.
  • Use black-and-white vector-style garment drawings on a white background.
  • Tables should be structured, readable, and factory-facing.
  • Use professional fashion technical terminology.
  • Keep all technical flats consistent with the uploaded drawing.
  • Do not add fashion poses, models, decorative backgrounds, moodboard imagery, lifestyle photos, or unnecessary graphic decoration.
  • Prioritise manufacturing clarity over visual styling.
  • Any inferred information must be labelled as “proposed”.
  • Any missing information should be shown as a professional placeholder in Red (e.g. [TBC supplier], [TBC Pantone], [TBC artwork file]).
  • Use metric measurements by default unless otherwise specified.
  • Ensure all garment measurements, construction details, materials, colorways, labels, and packaging instructions are internally consistent across the full tech pack.
