スライド 1

THE CLAUDE WORKFLOW BEHIND VIRAL CAROUSELS. （ブランド：Sociyell / SM Management & Growth）

スライド 2

Architecture over output. The secret isn’t just “good writing.” It’s building a system that remembers your brand. By using Claude’s Projects and artifacts, we create a design system that stays consistent across every carousel – no rebuilding your style each time.

スライド 3（ステップ1）

Lock Your Design System We don’t start fresh every time. We build a reusable system.

  1. Upload reference images (carousels you love, your brand examples)
  2. Ask Claude to identify colors, fonts, spacing from those references
  3. Define your writing rules (“no corporate jargon,” “use punchy sentences”)
  4. Save as a Claude Project – it remembers your style forever Now every carousel starts with your brand DNA already loaded.

スライド 4（ステップ2）

Build The Narrative Structure We use a retention-focused structure. The flow:

  • Slide 1: Pattern interrupt hook (stops scroll)
  • Slide 2: The “aha” moment (payoff that hooks them)
  • Slides 3–6: Information density (packed value)
  • Slide 7: The pro tip (bonus insight)
  • Slide 8: Frictionless CTA (clear next step) Each slide has a job. Not random value dumps.

スライド 5（ステップ3）

Use Artifacts To Build Slides This is the game-changer. Instead of describing slides in text, Claude builds them visually in Artifacts. What you can do:

  • Generate carousel layout as interactive prototype
  • See design and text side-by-side
  • Change colors/fonts with natural language
  • Export as high-res images or code for Figma Design + copy in one workflow. No context-switching.

スライド 6（ステップ4）

Run The Virality Audit Before exporting, stress-test the content. What to check:

  • Remove AI-isms – Delete words like “delve,” “unleash,” “navigate,” “revolutionize”
  • Check curiosity gaps – Does each slide make you need the next one?
  • Find the friction – What will people disagree with? (That’s what gets shares)
  • Visual contrast – Do visuals and text create thumb-stopping tension? Make Claude critique its own work. Ask: “What sounds too robotic here?”

スライド 7（ステップ5）

Adapt To Other Formats One carousel = wasted effort if you stop there. Repurpose into:

  • Reel script – Turn slides into 60-second video script
  • X/Twitter thread – Condense logic for text-only platform
  • LinkedIn article – Expand with data for professional audience
  • Newsletter – Restructure value slides into email format
  • Visual prompts – Generate image prompts for backgrounds Same core idea. 5 different formats. Claude handles all of it.

スライド 8

The tech is already here. The bottleneck isn’t tools. It’s workflow. Stop treating Claude like a text generator. Start using it as your design + content system. That’s how you go from random posts to scalable systems.

🎯 一言要約 Claudeを「テキスト生成ツール」から「ブランドDNAを記憶するデザイン＋コンテンツシステム」へと転換する5ステップのカルーセル制作ワークフロー。Claude Projects＋Artifactsを核に、設計→構成→ビジュアル→バイラル監査→リパーパスまでを一貫したシステムとして運用する。

🖥️ 業務効率化系｜Claudeカルーセル制作ワークフロー

📌 ポイント1：Claude Projects でブランドDNAを永続保存

リファレンス画像・カラー・フォント・ライティングルールをClaudeプロジェクトに保存することで、毎回スタイルを再構築しない。「ブランドを覚えているAI」として機能させるのが出発点。

📌 ポイント2：ナラティブ構造は8スライドの役割分担

フック→ahaモーメント→情報密度→プロtip→CTAの流れで各スライドに明確な役割を持たせる。「ランダムな情報の羅列」ではなく「リテンション設計されたストーリー」として組み立てる。

📌 ポイント3：Artifactsでデザインとコピーを同時確認

テキストでスライドを説明させるのではなく、Artifactsでビジュアルレイアウトを実際に生成。自然言語でcolor/fontを変更 → Figma出力まで1ワークフローで完結させる。

📌 ポイント4：バイラル監査はAI-ismsの除去から

「delve」「unleash」「navigate」などのAI特有表現を削除し、好奇心ギャップ・摩擦ポイント・ビジュアルコントラストをチェック。Claudeに「ロボット的に聞こえる部分を教えて」と自己批評させるのが実践的。

📌 ポイント5：1カルーセル = 5フォーマット展開

同じコンテンツコアをReel/X/LinkedIn/Newsletter/ビジュアルプロンプトに転換。制作コストを分散しながら露出を最大化するリパーパス設計。

💡 Creative Direction Note

🏢 AI推進ミッションへの活用提案

提案1：コネクト社内のSNS運用チームに「Claudeカルーセル制作SOP」として導入する この5ステップをそのまま社内運用マニュアルにできる。特にステップ1の「Claude ProjectsにブランドDNAを保存する」は、担当者が変わっても品質が落ちないための仕組みとして機能する。社員向けAI研修の”コンテンツ制作編”実習素材として即使える。

提案2：Artifactsを使ったライブデモをAI推進プレゼンに組み込む 「ClaudeでカルーセルをArtifactsで実際に作ってみせる」デモは、非技術者の社員への訴求力が高い。「テキストだけじゃなくてビジュアルも作れる」という認識転換を一瞬で起こせる最強のデモシナリオ。
