📝 要約

🎯 タスク管理アプリの各タスクに、AIチャット・メモ・ブラウザ・メール/Slack等のやり取りを統合した自作アプリ「PMHub」。機能別アプリでなくタスク別に作業し、人は判断と承認をさばく仕事に変わった、という実例

🗺️ 全体像

flowchart TD
    A[通知・依頼を1分ごとにAIが巡回] --> B[タスクとして自動追加]
    B --> C[タスクごとにAI担当・チャット・メモ・ブラウザ]
    C --> D[VICE: 副社長AIが振り分け]
    D --> E[メンバーAIが作業]
    E --> F[人は確認・承認をさばく]

📌 ポイント

1. 3列構成：タスク／AIチャット／メモ・ブラウザ

左がタスク管理、中央がClaude Codeのエンジンを使ったAI画面、右にメモとブラウザ。タスク1件ごとにAI担当がつき、AIの作業待ちの間に別タスクを進める。

2. 通知がタスクになる

メール・Slack・Instagram等を1分ごとにAIが巡回し、返信が要るものを自動でタスク化。請求書の作成〜メール下書きまで一連で処理できる。LINE等のDMは第三者サービス経由になるため、渡す情報は個人判断と注意している。

3. VICEと階層型オーケストレーション

置き場所に迷うものは「副社長」役のVICEに投げ、AIが適切なタスク・担当に振り分ける。リーダーAIがメンバーAIに分担させる組織図型。速くなる代わりに使用量も増えるため残量表示を出している。

4. 仕事の質が「作業」から「判断」へ

画面がこの1つに集約され、溜まったメールも気持ち悪いので処理する流れに。忘れない・見落とさない利点があるが疲れるので、さばく時間と編集など集中時間を分けている。スマホ版はメモ確認中心。

5. 仕組みの正体

Claude Codeのエンジン部分を画面を通さず直接動かし、見える部分だけを自作。API別料金ではなく契約済みプランの使用量内。家のMac miniと連携し、重い処理中は外出できる。

② 判断だけをさばく時間を決める 2時間さばく枠と制作に集中する枠を分ける運用を、明日の朝1枠だけ試す。
