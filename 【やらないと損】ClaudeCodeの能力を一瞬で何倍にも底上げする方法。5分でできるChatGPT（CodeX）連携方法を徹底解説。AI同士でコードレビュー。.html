📌 ポイント

1. セットアップ — 5分で完了するCodexプラグイン導入

claude-codeのターミナルでCodex CLIをインストールし codex login を実行。次に /plugin marketplace add openai/codex-plugin コマンドを実行するだけで連携完了。前提条件はChatGPT Plus（月$20）またはOpenAI課金プラン。設定後は mcp コマンドで接続確認できる。2026年3月末にAnthropicが公式機能として公開した。

2. セカンドオピニオン（アンサンブル効果） — 見逃しバグを別モデルが検出

ClaudeとCodexは異なるモデルのため、一方が見逃すバグをもう一方が検出できる。これを「アンサンブル効果」と呼ぶ。コードを書いた後に /codex review と打つだけで即座にレビューが返ってくる。開発だけでなく、提案書・事業計画書・リサーチ資料にも使える。動画内ではAPIの料金誤記のようなファクトエラーもCodexが検出した。

3. 並列処理 — Claude Code（実装）× Codex（リサーチ・ドキュメント）の同時作業

codex rescue コマンドを使うとCodexが裏側で動きながらclaude-codeがメイン作業を継続する。例：「大規模リファクタリング中にドキュメントを更新」「コード実装しながら提案資料を並行作成」など。AIエージェントチームを別モデルで構成することで単一モデルの限界を超えられる。

4. レビューゲート — AI同士のループ議論で品質を自動的に高める

/codex setup enable review-gate を使うと、Claude Codeが作ったコードをCodexがレビュー→問題があれば修正→再レビュー、というループが自動で回る。本番リリース前の重要なコードに特に有効。ループが長くなるとトークン消費が増えるため、重要箇所に限定して使うのが推奨。

5. 技術的背景 — なぜ競合AI同士が協業できるのか

Codexは一部オープンソースで公開されており、claude-codeのプラグインシステムは他社でも開発可能な仕組みになっている。OpenAIとAnthropicはモデル自体はクローズドだが、開発ツール層では「良いものは共用しよう」というオープンソース精神が根底にある。このため、MCPプラグイン経由で競合AIを呼び出すことが技術的に可能になっている。

💡 ゆりこの活用メモ

① 提案書・企画書のファクトチェックに使う デザイン案やブランド資料をclaude-codeで作った後、すぐに /codex review を流す習慣をつける。数字の誤り・表現の矛盾・論理の穴をChatGPT系の視点で拾えるので、クライアント提出前の最終チェックに組み込む。明日の案件作業の最後に1回試してみる。

② AI推進チームへの共有ネタとして使える 「Claude Code と Codex を連携させると2大AIが協業する」という話は社内AI勉強会のコンテンツになる。非エンジニアにも「セカンドオピニオン」という概念でわかりやすく説明できる。KONNEKTの定例でデモを1回やってみると食いつきが良さそう。
