📸 スライド内容

スライド 1（表紙）

A guide to design over willpower

この5つを直すだけで、人生は早く変わる。

スライド 2（現状診断）

今のあなた、たぶんこんな状態。

  • 始めても、終わらせられない
  • 気づくとスマホで時間を溶かしている
  • 忙しいのに、進んでいない気がする
  • 「やる気が出てから」を待ってしまう
  • 小さな乱れで、1日が崩れてしまう

だから止まっている感覚があるだけ。

スライド 3（01 FOCUS）

01 | FOCUS（problem → action）

足りないのは時間じゃない。集中。

fix it

  • 1日のタスクは3つまでに絞る
  • 起きてから60分はスマホに触らない
  • 45分の集中ブロックで仕事する

RULE If it’s not planned, it doesn’t happen. 計画されていないことは、起こらない。

スライド 4（02 DISCIPLINE）

02 | DISCIPLINE

モチベーションに頼るから、続かない。

fix it

  • 起きる時間と寝る時間を”絶対”にする
  • やる気がない日でも最低限はやる
  • 毎日記録する（ゼロの日を作らない）

RULE Discipline > Mood. 規律は、気分に勝つ。

スライド 5（03 ENVIRONMENT）

03 | ENVIRONMENT

毎日あなたを乱しているのは、環境。

fix it

  • 寝る前の5分で部屋をリセットする
  • 作業中はスマホを手の届かない場所に置く
  • 未来の自分に近い人をフォローする

RULE 環境が、行動をつくる。

スライド 6（04 STANDARDS）

04 | STANDARDS

“普通”を許してきた基準が、今のあなたを作っている。

fix it

  • 自分にも他人にも”低い努力”を許さない
  • 必要な場面では、はっきり断る
  • “普通”の基準を1段引き上げる

RULE 人生は、自分が許したものでできている。

スライド 7（05 DIRECTION）

05 | DIRECTION

忙しい。でも、進んでいない。

fix it

  • 30日間の目標を1つだけ決める
  • 週ごとのターゲットに分解する
  • 毎週日曜に進捗を見直す

RULE 方向がなければ、進歩もない。

スライド 8（クロージング）

本気で人生を変えたいなら、 このページに、毎日戻ってきていい。

Design > Willpower. 頑張らなくても、続く設計を。

意志ではなく、設計で続けるためのplannerを、近いうちに公開します。

📝 要約

🎯 「意志ではなく設計で人生を変える」5原則（FOCUS / DISCIPLINE / ENVIRONMENT / STANDARDS / DIRECTION）— 頑張る根性ではなく、続く仕組みを作る。

🎯 01. FOCUS — 集中の設計

足りないのは時間じゃなく集中。1日のタスクは3つまで、起床後60分はスマホに触らない、45分の集中ブロックで仕事する。「計画されていないことは起こらない」 がルール。「やることリスト」を膨らませる前に、削ることから始める。

🔁 02. DISCIPLINE — 規律 > 気分

モチベーションに頼ると続かない。起床・就寝時刻を”絶対”にし、やる気ゼロの日でも最低限はやる、毎日記録してゼロの日を作らない。Discipline > Mood. 気分の波に決定権を渡さず、規律にコミットする。

🏠 03. ENVIRONMENT — 環境設計

毎日あなたを乱しているのは環境。寝る前5分で部屋リセット、作業中はスマホを手の届かない場所へ、未来の自分に近い人をフォローする。環境が、行動をつくる。 意志ではなく物理配置・SNSフィードを設計で変える。

⬆️ 04. STANDARDS — 基準を1段上げる

“普通”を許してきた基準が今の自分を作っている。自分にも他人にも”低い努力”を許さない、必要な場面ではっきり断る、“普通”の基準を1段引き上げる。人生は、自分が許したものでできている。

🧭 05. DIRECTION — 方向の設計

忙しいのに進んでいない人は方向がない。30日間の目標を1つだけ決め、週ごとのターゲットに分解、毎週日曜に進捗を見直す。方向がなければ、進歩もない。 量の前に、向きを決める。

💡 ゆりこの活用メモ

① 月曜の朝、今週のタスクを「3つ」に削る ゆりこの「1日1つが基本」スタンスと完全一致。月曜会議（/monday）の「今週の3つ」を「絞り込みフェーズ」として再定義する。やる気じゃなく、絞ったから進む。

② 起床後60分のスマホ断ち＝/ohayo工程表の前にスマホ触らない 朝の最初の60分をデザイン作業や1日設計に充てる。スマホ・Slack・SNSは60分後。ベッドサイドの充電場所をリビングに移すだけで物理的に距離が生まれる。

③ 日曜21時を「30日目標の見直しタイム」に固定 /eod を日曜だけ拡張し、「30日目標の進捗チェック」を1問追加する。クリエイティブディレクター目標を30日単位に分解して、毎週日曜に向き合う仕組みにする。

💡 Creative Direction Note

🎬 Frenzy Lazy（@frenzy.lazy）のクリエイティブ設計

① “Design > Willpower” という強い思想軸 投稿全体が「意志に頼るな、設計で続けろ」という一貫したメッセージで貫かれている。ラスト8枚目で「意志ではなく、設計で続けるためのplannerを公開します」と商品予告に着地する構造が綺麗。思想 → 5原則 → プロダクト誘導 の3段ファネルが完成している。

② ビジュアル文法：モノクロ寄りの落ち着いたトーン + セリフ体の白文字 アジアン系インテリア・ワークスペース・撮影現場・モードなショット——「働く女性のリアルな日常」を切り取りつつ、彩度を落として統一感を出している。タイトル番号は 01 | のパイプ区切りで雑誌的・ブランド誌的に。英語と日本語の2言語混在（“fix it” “RULE” “Design > Willpower.“）が海外ガール感を演出。

③ MEADOW.（ゆりこのライフブランド）への応用ヒント MEADOW.も「頑張りすぎず、続く生活設計」が思想の中核。Frenzy Lazyの「fix it → RULE → 一言キャッチ」のフォーマットは、MEADOW.のコレクション機能（カフェ・服・友達）と相性が良い。コレクション追加時に「今日のRULE」を1行添える機能、月刊MEADOW Magazineの巻頭に「今月のDESIGN > WILLPOWER」を載せる、などが応用できる。

④ “計画されていないことは起こらない” は CORIN の存在意義そのもの ゆりこ + CORIN の関係は、まさに「意志ではなく設計で続ける」を実装している。Day Planner・/monday・/ohayo は全部 “Design > Willpower” のツール群。この思想をCORINのキャラ文脈に正式に取り込むと、ゆりこ自身のブランディング軸（クリエイティブディレクター + 設計者）にも繋がる。
