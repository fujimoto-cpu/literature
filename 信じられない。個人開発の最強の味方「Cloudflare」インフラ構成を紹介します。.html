📝 要約

🎯 個人開発でウェブサービスを作るなら「Cloudflareスタック」が最もコスパが良い、という技術構成解説動画。フロントエンドからDB・ストレージ・認証・決済・デプロイまで、Claude Codeなどのコーディングエージェント上で指示だけで完結できる点が最大の魅力。

🗺️ 全体像

flowchart TD
    A[フロントエンド Next.js/Benext] -->|APIリクエスト| B[バックエンド Route Handlers/Hono]
    B --> C[(データベース Cloudflare D1)]
    B --> D[ファイルストレージ Cloudflare R2]
    E[認証 BetterAuth/Clerk] --> B
    F[決済 Stripe] --> B
    G[ホスティング Cloudflare Workers] --> A
    G --> B

📌 ポイント

1. データベースはCloudflare D1 — 無料枠がSupabaseより太い

D1はSQLiteベースで、書き込みが直列（同時並行書き込み不可）というデメリットはあるが、無料枠で読み取り1日500万行・書き込み10万行・データベース合計5GB・転送量とエグレスが無制限という点がSupabase（無料枠500MB・転送量5GBまで）より圧倒的にコスパが良い。ただし1データベースあたり500MBを超えると5ドル課金しても10GBまでしか伸ばせないのが弱点。

2. 認証はBetterAuthが完全無料、Clerkは月5万ユーザーまで無料

BetterAuthは無料だがユーザー管理・セキュリティを自前で担う必要があり、メール送信も別サービス依存。Clerkはセキュリティ・MFA・アカウント切り替えまで任せられて月5万アクティブユーザーまで無料だが、セッション有効期間を7日超に伸ばすには25ドルの課金が必要という落とし穴がある。

3. 決済はStripe一択、ファイルストレージはR2一択

決済は手数料3.6%で実装のしやすさ・ドキュメントの豊富さからStripeが最有力（複数ユーザー間の売買システムを作るならStripe Connect）。ファイルストレージはR2が無料枠10GB＋転送量無制限で、画像を1日4000枚アップロードする自社SNSアプリでも月3ドル程度に収まっている実例を紹介している。

4. ホスティングはCloudflare WorkersがVercelより有利

転送量が無料（Vercelは1TB超で課金）、無課金でも商用利用可（Vercelは無料枠だと商用利用不可・月20ドル必要）という2点でWorkersが優位。Next.jsをWorkersにデプロイする新アダプター「Benext」も紹介されている（まだベータ版）。
