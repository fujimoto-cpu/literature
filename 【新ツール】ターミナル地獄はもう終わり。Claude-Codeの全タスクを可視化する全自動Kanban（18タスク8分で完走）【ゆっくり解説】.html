📝 要約

🎯 Claude Codeのタスク実行状況をリアルタイムでブラウザ可視化するOSSツール「Claude Task Viewer」の紹介動画。18タスクを8分18秒で全自動完走させながら、カンバン表示・サブエージェント3並列レビュー・依存グラフの威力を実演する。

📌 ポイント

1. Claude Task Viewer — 「観測優先」という逆転発想

L1ADさんが公開するOSS。普通のタスク管理ツール（Trello等）は人間がカードを動かすが、このツールは人間が一切触らず、Claude Codeがタスク状態を持ってブラウザに映し出す。「Observation over Control（観測優先）」の思想で、表示と実態が絶対にずれない設計。起動は npx claude-task-viewer の一発のみで、設定ゼロで全セッションを自動検出する。公開3週間で500スターに到達し、スターをつけた人の10%がコピーして実際に触っている（通常OSSの1〜3%と比べ異例の熱量）。

2. カンバン表示でAIの思考が「見える」

タスクはPending / In Progress / Done の3列で表示され、依存関係が解消されたカードが順次In Progressに移動する様子をリアルタイムで観察できる。ガントチャート表示に切り替えると各タスクの所要時間がバーチャート風に並ぶ。完了通知はデスクトップ通知（ベルアイコンでオン/オフ切替）、完了音あり。7日以上更新がないセッションは自動アーカイブ。キーボードショートカット（?でヘルプ、Dでタスク削除）も完備。

3. 要件書の書き方がカギ——タスク＋依存関係を明記する

「TODOアプリをTDD（テスト駆動開発）で作り、最後にコードレビューまで行う」という要件書をClaude Codeに渡すと、18タスクを自動分解して依存グラフ付きで登録する。各カードには依存先タスク番号が明記され、どのタスクが終われば次が解放されるか一目でわかる。テストファーストの実装（失敗するテストを先に書いてから実装する）も依存グラフで自動的に守られる。

4. サブエージェント3並列レビュー——同時に3つの視点でチェック

1つのメッセージで3つのサブエージェントを同時に起動し、「コーディング規約」「セキュリティ」「パフォーマンス」の3観点を並列チェックする。カンバン上では11・12・13番のカードが同時にIn Progressへ移動し、約6分半後にほぼ同時に完了列へ着地。サブエージェントは互いに独立した別の「頭」なので3つ並列でも干渉しない。「見えないAIの思考がちゃんと見える」という体験がこのツールの真骨頂。

💡 ゆりこの活用メモ

① 明日の朝、npx claude-task-viewerを試す ターミナルで npx claude-task-viewer を打てばすぐ動く。セットアップ不要。Claude Codeで何か作業するとき（会社のAI推進資料作成でも可）に一緒に起動しておくだけでOK。

② 要件書テンプレを1本作っておく 動画概要欄に18タスク自動分解の要件書プロンプトが公開されている（https://www.youtube.com/watch?v=naH3_LLaU0I の概要欄）。コピペしてClaude Codeに渡すだけで全自動Kanbanが動く。社内AI推進のデモ素材としても使えるので今週中に試す。
