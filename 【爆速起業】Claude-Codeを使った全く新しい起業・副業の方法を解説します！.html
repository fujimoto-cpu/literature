📌 ポイント

1. 起業の本質 — 江戸時代から変わらない3フェーズ

「集客 → 商品を作る → 販売する」の3ステップが起業のすべて。江戸時代の飲食店も看板で集客して料理を売っていたのと同じ原理。複雑に考えすぎず、自分のパターンでこの3つを当てはめるだけ。SNSという最強の無料集客ツールが現代にはあるので、かつてより圧倒的に参入コストが低い。

2. 商品設定 — 自分の「一番時間を投下してきたこと」が強み

営業経験 → 営業ノウハウの教材、編み物得意 → ハンドメイド販売、コード書ける → アプリ開発・受託、という形で過去の時間投資が商品になる。AI活用の恩恵を最大化したいなら、アプリ開発・講座・記事コンテンツなどデジタル系が相性◎。物理商品はAIで自動化しにくい。

3. Claude Codeで1日2日でMVP開発

動画内でボトルメッセージ交換ウェブアプリ（YouTube URL匿名交換サービス）を約30分で構築デモ。Next.js + Supabase（Taas DB）+ Stripe決済 + Cloudflare Pagesでデプロイ。プランモード→要件詰め→Auto Accept Editで自律開発。エンドツーエンドテストまで自動で完了。月額100ドル（約15,000円）のMaxプランが費用対効果◎。

4. CC Company（仮想組織）で事業をシステム化

作者が自作した「CCカンパニー」プラグイン（OSS・無料）を使うと、Claude Code上に仮想組織を構築できる。目標・タスク管理・ダッシュボード機能付き。3つの質問に答えるだけでAI秘書がセットアップされ、ビジネス知識が蓄積されていく「相棒」になる。CORIN（ゆりこのCEO AI）と同じ思想。

5. 起業マインド — ハズレくじを早く引く確率論

「一発で当てに行く」より「残りのハズレをいかに早く消化するか」がビジネスの正解。10本中1本の当たりくじに向けて、Claude Codeで素早く試作→失敗→次へ。1ビジネスのサイクルが数日に短縮された今、失敗のコストが激減している。だから量で挑戦できる時代になった。

💡 ゆりこの活用メモ

① Claude Codeで「爆速LP作成」をビジネスプロセスに組み込む デザイン提案の際、ランディングページのプロトタイプをClaude Codeで1日以内に作って見せる。Stripe決済リンクを1本貼るだけでマネタイズの入口になる。クライアントへの提案速度が上がり、差別化できる。

② AI導入研修で「スモールビジネス立ち上げ体験」をコンテンツ化する 社員向けにClaude CodeでMVP（最小限のサービス）を1日で作る体験ワークショップを設計できる。「起業できる感覚」を体験させることがAI導入研修のモチベーション起点になる。
