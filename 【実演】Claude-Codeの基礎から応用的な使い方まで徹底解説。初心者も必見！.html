📝 動画要約

アドネス株式会社の三上氏が「Claude Codeを成果に繋げるための5ステップ攻略法」を実演解説した動画。機能説明ではなく「仕事の成果に直結する使い方」にフォーカスしているのが特徴。

5ステップの概要：

  1. 定型業務の効率化 — 作業フォルダを設定し、CLAUDE.mdはClaude Code自身に自動生成させる。やりたいことを言葉で伝えるだけでよい
  2. 自立実行（ルーティン化） — 定期実行ルーティンをClaude Codeに作らせる。人が介在せずメールや資料作成が自動完結する状態を目指す
  3. 外部連携による能力拡張（腕生やし） — Gmail・Googleカレンダー・YouTube Data APIなどMCPやAPIをコネクタから接続。やりたいことに合わせて腕を探して付ける
  4. ワークフローの最適化 — チームメンバーにも渡せる安定した形に整える（出荷可能な状態）
  5. 意思決定の自動化（話すだけで仕事が終わる） — ゴールツリーをAIに連携させることで、AIが自分の状況を理解し、話すだけで仕事が進む状態を実現

重要ポイント： AIを触ることが目的になっている人が多い。ステップを踏まずにいきなり高度な自動化をしようとすると失敗する。明確な目標があってこそAIは機能する。Webモードは端末内ファイルにアクセスできないため、デスクトップアプリかCLIインストール版の使用を推奨。
